# 对话

本会话里每一轮对话记录成一条：从你的输入（或 AI 的提问）开始，到这一轮结束时的回答、耗时、token、用到的工具与结束原因。

## 它解决什么

「刚刚那轮你到底用了什么、花了多少、为什么停下了」——终端里滚回去看很难找，而且工具调用的成败、token 用量都不在正文里。这个页签把每一轮压成一行，点开看全貌。

## 什么算一轮

| 起点 | 标记 | 触发 |
|---|---|---|
| 你提交输入 | `·` | `prompt.submit` |
| AI 发起提问 | `◆` | `tool.call` 的 `AskUserQuestion` |
| 续轮（你没打字，引擎自己开的） | `↻` | `turn.start` 且当前没有进行中的轮 |

- **你提交的输入全部记录**：普通文字、slash 命令、带附件、在 AI 回复中途追加的，都会新开一轮。
- **技能预置文本不算**：以 `Base directory for this skill:` 开头的提交被忽略。
- **前一轮未结束就来了新输入**：前一轮标记为已结束（没有结束原因），新轮开始。
- **子代理的回合不算**：`agentId` 非空的事件全部忽略，只有主循环进对话。

## 一轮什么时候结束

引擎的 `turn.complete` 到达时，补全：
- 结束原因：回答 / 中断 / 拒绝 / 报错
- 耗时（毫秒）
- AI 最终可见回答全文
- token 用量：输入 / 输出 / 缓存读 / 缓存写，以及模型 id

中断或报错时引擎不报用量，对应字段显示 `—`，不显示 0。

**已知缺口**：引擎在某些情况下不触发 `turn.complete`（请求没发出去、被拒绝、热重载重置了游标）。这些轮次停在「进行中」，不会伪造为已完成。

## 会话统计

对话页签是一张主卡；卡片顶部一块「会话」统计，回答「这次会话到底花了多少、做了什么」：

```
╭─ 💬 对话 ────────────────────────────────────────────────── · 6 项 ╮
─ 会话
  claude-opus-5-5（6 轮） 入 120000 · 出 8000 · 缓存读 340000 · …
  合计 入 120000 · 出 8000 · 缓存读 340000 · 缓存写 21000
  工具 5 种 · 42 次
  命令 17 次

▸ · 06:13 把分支状态改成一仓一行

1 项 · 点行看详情                                                
╰───────────────────────────────────────────────────────────────────╯
```

「工具」「命令」两行可下钻。详情页本身是独立页面：卡片标题带区域 emoji，字段标签带图标，长值自动换行。

- **模型行**：按 `usage.model` 分组，每行含轮数与该模型的四项 token 之和；末尾是全部模型的合计。
- **工具 / 命令**：两行都可以点。工具行是「种类数 · 总调用次数」（种类 = 不同工具名），命令行是 `Bash` 的总调用次数。
- 没有任何已结束的轮次时，显示「（暂无用量）」。
- 面板高度 < 20 行时，只显示第一行模型摘要，其余进下钻。

## 下钻

从统计往下可以一层层点进去。每一层都是**同一张主卡**，当前层级的名字就是卡片标题；右上角的「← 返回」（或 `b`）逐层退回：

```
会话统计 ──点工具──▶ 工具分组（Bash 9 次 / Read 4 次 / …）
                       └─点某个工具──▶ 该工具的每次调用（时间 ✓ 摘要 耗时）
                                         └─点某次调用──▶ 完整参数与结果
会话统计 ──点命令──▶ 每次 Bash 的原文，最新在前 ──▶ 完整参数与结果
```

| 层级 | 标题 | 空态 |
|---|---|---|
| `stats-tools` | `工具 · N 种 · M 次` | `本次会话没有调用工具` |
| `stats-commands` | `命令 · N 次` | `本次会话没有执行命令` |
| `all:<工具名>` | `<工具> · N 次` | `本次会话没有调用 <工具>` |
| `tool:<轮次>:<工具>` | `<工具> ×N · <该轮输入首行>` | `本轮没有调用 <工具>` |
| 一次调用 | `✓/✗ <摘要>`，含参数与结果 | — |

## 返回

所有详情与下钻层共用同一个返回入口：**内容区右上角**的「← 返回」，`b` 键等价。规则固定：

- 下钻层 → 上一层
- 列表的详情 → 该列表
- 最外层（页签自己的列表）不显示返回

OpenSpec 详情、分支 diff 的文件列表与单文件、提示音页用的是同一个按钮，位置与文案一致。

## 工具归属

AI 在这一轮里调用的每个工具都记到这一轮名下，按**工具名**聚合：

```
Read ×2 · Bash ×1（失败 1）
```

- 只有调用返回后才记一次（不需要先占位再回填）。
- 子代理的工具调用不记。
- `AskUserQuestion` 本身不记为工具（它是新一轮的起点）。
- MCP 工具也计入这里；参数和结果是 MCP 页签的职责，这里只给名字、次数与失败数。

## 详情里的工具可以点

轮次详情底部那行 `Bash ×3 · Write ×4`，每个工具名都是可点的：

- 点 `Bash ×3` → 该轮 3 次 Bash 的具体调用（时间、成败、耗时、命令原文）
- 点其中一条 → 该次调用的完整参数与结果
- 点 `Skill ×N` → 该轮每个技能各调了几次，再点看参数

每轮每个工具最多保留**最近 50 条**调用记录；每条摘要截断到 200 字、参数 2 000 字、结果 400 字。

## 列表

```
<光标:2><标记:1><时间:5><首行摘要>
▸ ·06:13 把分支状态改成一仓一行
  ◆08:40 按轮次还是按消息逐条？
  !↻09:02 续轮
```

- 新的一轮在最上面。
- 摘要取输入的第一行。
- **失败态**：结束原因是中断/拒绝/报错，或本轮有工具调用失败 → 标记槽画 `!`，`error` 色。

## 详情与折叠

详情自上而下：时间、类型、命令、附件 → **输入** → **回答** → 工具 → 用量 → 结束。

| 段落 | 上限 | 超出时 |
|---|---|---|
| 输入 | 6 行 | `…（共 N 行，已显示 6 行）` + `[ 查看全部输入 ]` |
| 回答 | 半屏（`max(3, ⌊bodyRows/2⌋)` 行） | `…（共 M 行，已显示 N 行）` + `[ 查看全部回答 ]` |

- **不超就不折**：短内容原样全展，不出现说明行和按钮。
- 行数按显示宽度估算（中文占 2 格），窗口变宽会重算。
- **工具 / 用量 / 结束不折叠**，始终在同一屏内可见。
- 点「查看全部」进入全屏只读视图，`b` 的层级：全屏 → 详情 → 列表。

## 上限

最多保留 400 轮，超出丢弃最旧的。单轮输入与回答各截到 20,000 字符。
