# 其他页签 · prompt 收藏

面板第 5 个页签「其他」先给功能入口，目前里面只有 **prompt 收藏**：把常用 prompt 存起来，点一下复制，按使用频率排序。

## 它解决什么

评审、回归、提交、排查这类话术每次重复输入，或者翻历史记录复制。「其他」提供一个固定的收藏架：添加一次，之后点行即复制；面板没开时也能用命令随时收藏。

## 数据从哪来

- 收藏存在用户级全局文件 `~/.claude/bench-prompts.json`（`{ version, prompts: [{ id, text, copies, createdAt }] }`），换项目、重开会话都还在。
- 文件是唯一数据源：进入功能页、执行添加/复制/删除前都会重新读文件，而不是只读会话启动时读到的那一份。`/clear` 会结束会话并换一个会话 ID，**不会**再触发 `session.start`，只靠启动时读一次的话列表会变空、下一次添加还会把文件覆盖掉。
- 添加只走斜杠命令 `panel-prompt-add`；面板本身不提供输入框（引擎的 mobile 端没有 `Input`）。
- 复制走引擎的面板剪贴板 `$.ui.copy`，终端侧与 `/copy` 同一条路径。

## 页面骨架

**入口页**（标准列表页）：

```
  OpenSpec  对话  MCP  提示音  其他                              1 项
──────────────────────────────────────────────────────────────
 功能 1 个
──────────────────────────────────────────────────────────────
▸ prompt 收藏
──────────────────────────────────────────────────────────────
1 项 · 点行进入                                          1–5 页签
分支  | dev-panel  main                                         预览
```

**功能页**（安静页）：没有页签、状态轨道与分支轨道；标题 `prompt 收藏`，右上 `← 返回`（`b` 等价）；每行：

```
<prompt 首行>                                   ×12  删除
```

- 行是 `plain` Button，**点行复制全文**，不进入详情；
- 行尾 `×N` 是复制次数，muted；<56 列时丢弃；
- 没有收藏时显示 `还没有收藏。用 /panel-prompt-add 添加。`；
- 文件读不出来时，页面顶部先显示一行「读取失败：<原因>」。

## 添加

```
/panel-prompt-add 帮我把这段代码做一次独立评审
```

- 参数是**单行文本**，首尾空白会被去掉；
- 与已有收藏完全相同（trim 后）时**不新增**，回「已存在：<首行>」；
- 成功回「已收藏：<首行>」，**不会自动打开面板**；
- 空参数回用法说明；
- 写入失败回「保存失败」。

## 复制与计数

- 复制成功：次数 +1 并写回文件，页脚短暂显示「已复制」（约 2 秒）；
- 复制失败：页脚显示「复制失败：<原因>」，**次数不变**；
- 终端用 OSC 52 时无法回报真实写入，按引擎返回的 `isCopied` 计数。

## 排序

- 复制次数降序；次数相同按新增时间倒序（新的在前）。
- 复制当下**不重排**；每次进入功能页（从入口进入、重开面板后再进入、`/clear` 后再进入）都重新读文件并按最新数据重排。

## 删除

- 行尾 `删除` → 本行变成「确认删除？ 删除 取消」；
- 点「取消」保留；点「删除」才真正移除并写回文件；
- 不提供编辑，想改就删了重加。

## 键位与窄屏

- 页签热键 `5`；页脚提示 `1–5 页签`，<40 列缩为 `1–5`。
- 24 列下页签只显示短名：`Spec / 对话 / MCP / 音 / 其他`。

## 边界

- 不设条数与长度上限（用户已确认）；文件会随使用增长。
- 不同步、不分享、不跨机器。
- 读取失败不覆盖原文件；下一次真正的写入才会重写它。
