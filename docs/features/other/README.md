# 更多页签 · 设置与 prompt 收藏

面板第 4 个页签「更多」集中三件事：**prompt 收藏**、**提示音**、**编辑器**。每一项进入一个安静页，返回回到「更多」。

## 它解决什么

评审、回归、提交、排查这类话术每次重复输入，或者翻历史记录复制；提示音与编辑器又只是设置，不应该和主功能抢页签。这里给出一个固定的设置入口。

## 数据从哪来

- 收藏分两级：全局 `~/.claude/bench-prompts.json` 与项目 `<session.root>/.bench/prompts.json`（`{ version: 2, prompts: [{ id, text, copies, launches, scope, createdAt }] }`），换项目、重开会话都还在；项目级只在该项目里可见。
- 文件是唯一数据源：进入功能页、执行添加/发射/复制/删除前都会重新读文件，而不是只读会话启动时读到的那一份。`/clear` 会结束会话并换一个会话 ID，**不会**再触发 `session.start`，只靠启动时读一次的话列表会变空、下一次添加还会把文件覆盖掉。
- 读取时合并两级；写入时只写对应作用域的文件；任一文件损坏时保留另一级可用数据并提示是哪一级失败，**不覆盖**损坏文件。
- 旧 `version: 1` 文件按全局迁移：补 `launches: 0`、`scope: "global"`。
- 添加只走斜杠命令 `panel-prompt-add`；面板本身不提供输入框（引擎的 mobile 端没有 `Input`）。`--project` 前缀写项目级，默认全局。
- 发射走 `$.prompt.fill`（预填，不提交）；复制走 `$.ui.copy`，终端侧与 `/copy` 同一条路径。
- 编辑器读取插件 config 行 `bench.editor`，选择通过 `$.config.set` 写回。

## 页面骨架

**入口页**（标准列表页）：

```
  会话  变更  代理  更多                                          3 项
──────────────────────────────────────────────────────────────
 功能 3 个
──────────────────────────────────────────────────────────────
▸ prompt 收藏
  提示音
  编辑器  终端内
──────────────────────────────────────────────────────────────
3 项 · 点行进入                                            1–4 页签
分支  | dev-panel  main                                         预览
```

**功能页**（安静页）：没有页签、状态轨道与分支轨道；标题分别为 `prompt 收藏` / `提示音` / `编辑器`，右上 `← 返回`（`b` 等价）。

### prompt 收藏

每行：

```
<prompt 首行>                        全局  ×12  发3  复制  删除
```

- 行是 `plain` Button，**点行把全文预填进输入框**（不提交、不进入详情）；
- 输入框不可用（`-p` / headless / 对话框）时回退复制，页脚提示「已复制（输入框不可用）」；
- 行尾 muted：作用域 `全局 / 项目`、复制次数 `×N`、发射次数 `发 M`；<56 列丢弃作用域与 `发 M`，`×N` 保留；
- 独立的 `复制` 按钮只做剪贴板，复制次数 +1、发射次数不变；
- 没有收藏时显示 `还没有收藏。用 /panel-prompt-add 添加。`；
- 文件读不出来时，页面顶部显示「<全局/项目>收藏读取失败：<原因>」。

### 提示音

四行开关（`总开关 / 需要决策 / 任务完成 / 任务异常`），行首 `开` / `关`，行尾 `▶ 试听`；点行切换、点试听发声，行为与[提示音文档](../sounds/README.md)一致。

### 编辑器

列出 `bench.editor` 的可选值，当前项 `▸` + accent；点选调用 `$.config.set({ key: 'bench.editor', value })`，成功后面板立即使用新编辑器，失败在页脚说明原因。组织策略锁定时只读。

## 添加

```
/panel-prompt-add 帮我把这段代码做一次独立评审
/panel-prompt-add --project 这个仓库专用的回归话术
```

- 参数是**单行文本**，首尾空白会被去掉；`--project` 前缀写项目级，默认全局；
- 与同一作用域已有收藏完全相同（trim 后）时**不新增**，回「已存在：<首行>」；同一句话可以同时存在于全局与项目两级；
- 成功回「已收藏：<首行>」/「已收藏（项目）：<首行>」，**不会自动打开面板**；
- 空参数回用法说明；
- 写入失败回「保存失败」。

## 发射、复制与计数

- **点行发射**：全文进入输入框，发射次数 +1；不自动提交；
- 输入框不可用：回退复制，复制次数 +1，页脚「已复制（输入框不可用）」；
- 独立 `复制`：复制次数 +1，发射次数不变；页脚短暂「已复制」（约 2 秒）；
- 复制失败：页脚显示「复制失败：<原因>」，次数不变；
- 终端用 OSC 52 时无法回报真实写入，按引擎返回的 `isCopied` 计数。

## 排序

- 按使用次数（复制 + 发射）降序；次数相同按新增时间倒序（新的在前）。
- 发射或复制当下**不重排**；每次进入功能页（从入口进入、重开面板后再进入、`/clear` 后再进入）都重新读文件并按最新数据重排。

## 删除

- 行尾 `删除` → 本行变成「确认删除？ 删除 取消」；
- 点「取消」保留；点「删除」才真正移除，并只写回它所属作用域的文件；
- 不提供编辑，想改就删了重加。

## 键位与窄屏

- 页签热键 `4`；页脚提示 `1–4 页签`，<40 列缩为 `1–4`。
- 24 列下页签只显示短名：`会话 / 变更 / 代理 / 更多`。
- 编辑器行在任何宽度都显示当前值；prompt 收藏页 <56 列丢弃 `×N`。

## 边界

- 不设条数与长度上限（用户已确认）；文件会随使用增长。
- 不同步、不分享、不跨机器。
- 读取失败不覆盖原文件；下一次真正的写入才会重写它。
