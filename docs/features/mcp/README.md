# MCP 页签

按 MCP 服务器分组，看本会话里每次调用了什么工具、传了什么参数、成功还是失败、花了多久。

## 它解决什么

MCP 工具调用在终端里只显示一行摘要，参数和结果都被折叠。查「刚才那次 oracle_query 到底传了什么 SQL、为什么失败」时没有好用的地方。这个页签按服务器归档每次调用。

## 记什么

只记 `mcp__*` 开头的工具调用（内置工具如 `Read`、`Bash` 不进这里）。

每次调用记：

| 字段 | 内容 |
|---|---|
| 时间 | 调用开始时刻 |
| 工具名 | 去掉 `mcp__<server>__` 前缀后的名字 |
| 服务器 | `e.mcp.name`，缺失时记 `mcp` |
| 耗时 | 毫秒；调用进行中时为 `-1` |
| 成功 | `deny` 或 `isError` 都为失败 |
| 参数 | 事件除 `tool` / `tool_use_id` / `mcp` 外的全部字段，JSON 缩进 |
| 结果 | 返回给模型的文本，截到 4,000 字符 |

参数截到 20,000 字符，超出加 `…`。

## 列表

一屏一张主卡（`🔌 MCP`），每行一个服务器：

```
╭─ 🔌 MCP ──────────────────────────────────────── · 2 项 ╮
▸ oracle-apex    12 次 · 最近 09:41
  playwright     3 次 · 最近 08:12
╰────────────────────────────────────────────────────────╯
```

按服务器分组，组内按时间倒序。详情同样是这张主卡，服务器名作卡片标题。

## 详情

```
oracle-apex（12 次）

09:41 ✓ oracle_query 320ms
  {
    "query": "SELECT * FROM APP.ORDERS WHERE ..."
  }
09:38 ✗ oracle_execute 1200ms
  ...
```

每个调用最多显示参数前 8 行；分组内最多显示最近 40 次。

## 上限

最多保留 600 次调用，超出丢弃最早的。
