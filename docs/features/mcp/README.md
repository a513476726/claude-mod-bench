# MCP 页签

按 MCP 服务器分组，看本会话里每次调用了什么工具、传了什么参数、成功还是失败、花了多久。

## 它解决什么

MCP 工具调用在终端里只显示一行摘要，参数和结果都被折叠。查「刚才那次 oracle_query 到底传了什么 SQL、为什么失败」时没有好用的地方。这个页签按服务器归档每次调用。

## 记什么

只记 `mcp__*` 开头的工具调用（内置工具如 `Read`、`Bash` 不进这里）。

每次调用记：

| 字段 | 内容 |
|---|---|
| 时间 | 调用开始时刻 |
| 工具名 | 去掉 `mcp__<server>__` 前缀后的名字 |
| 服务器 | `e.mcp.name`，缺失时记 `mcp` |
| 耗时 | 毫秒；调用进行中时为 `-1` |
| 成功 | `deny` 或 `isError` 都为失败 |
| 参数 | 事件除 `tool` / `tool_use_id` / `mcp` 外的全部字段，JSON 缩进 |
| 结果 | 返回给模型的文本，截到 4,000 字符，截断处写明「已达存储上限 4,000 字」 |

参数截到 20,000 字符，超出时在截断处写明「已达存储上限 20,000 字」，不再只留裸 `…`。

## 列表

平铺页：页签 → 规则线 → 服务器统计轨道 → 规则线 → 平铺行 → 规则线 → 页脚 → 分支轨道。每行一个服务器：

```
  OpenSpec      对话    MCP    提示音                        2 项
──────────────────────────────────────────────────────────────────
 服务器 2 个
──────────────────────────────────────────────────────────────────
▸ MCP   12 次  oracle-apex
  本地   3 次  Bash
──────────────────────────────────────────────────────────────────
2 项 · 点行看详情                                          1–4 页签
```

- 第一列是标签（`MCP` / `本地`，structural subtle 色），第二列调用次数，名称列吸收剩余宽度。
- 行名是服务器；最近一次时间放在详情的状态行右侧，不占列表列。
- 点行进入该服务器的调用列表（安静页）；调用行由时间 + `成功`/`失败` 标签 + 工具名 + 耗时组成。

## 详情

调用列表与单次调用都是**安静页**：没有页签与分支轨道，完整标题按宽度折行，状态行左为 `MCP` / `本地` 标签、右为调用数；右上角 `← 返回`：

```
  oracle-apex                                                   ← 返回
  MCP                                                     12 次
──────────────────────────────────────────────────────────────────
09:41 成功 oracle_query 320ms
  {
    "query": "SELECT * FROM APP.ORDERS WHERE ..."
  }
09:38 失败 oracle_execute 1200ms
  ...
```

每个调用显示它的时间、成功/失败、完整参数；详情按字符预算取内容，不再固定「最近 40 次 × 每次 8 行」。超出预算时末尾写「… 还有 N 次调用未显示（达到显示上限）」。内容超屏由面板滚动，`← 返回` 固定在视口右上角。

## 上限

最多保留 600 次调用，超出丢弃最早的。
