# 代理（子代理花名册）

面板第 3 个页签「代理」（快捷键 `3`）：列出本会话启动的子代理与 teammates，回答「有几个在跑、在等什么、花了多久、失败了没有」。只读，不干预执行。

## 它解决什么

子代理、teammates、workflows 是主流用法，但原生界面里它们是黑盒：看不到有几个在跑、谁失败了。代理页把每个代理压成一行，状态是第一列；点开能看它的工具数、最后输出与对话摘录。

## 数据从哪来

- `agent.spawn`：新增一行，记 id、类型、描述、父代理与开始时间（状态 `running`）；
- `turn.start`（带 `agentId`）：该行置为 `running`；
- `turn.complete`（带 `agentId`）：`reason: answer` → `completed`，其余 → `failed`；记结束时间与最终回答；
- `tool.call`（带 `agentId`）：工具数 +1，失败时失败数 +1；
- 打开代理页时调用 `$.agent.list()` 对账：补漏、校正状态；引擎丢弃的条目**保留到会话结束**，不会因 list 缺失而删除；
- 代理事件不写入主对话的轮次列表。

## 花名册

```
  会话  变更  代理  更多                                          3 项
────────────────────────────────────────────────────────────────────
 代理 3
────────────────────────────────────────────────────────────────────
▸ 运行  Explore      看依赖树                    2m12s  工具 5
  运行  Plan         整理迁移步骤                 1m03s  工具 2
  完成  Explore      写回归测试                  8m40s  工具 7
────────────────────────────────────────────────────────────────────
3 项 · 点行看详情                                              1–4 页签
```

- 状态：运行（claude）/ 等待（warning，含 `pending`）/ 空闲（subtle）/ 完成（success）/ 失败（error）/ 终止（error）。
- 排序：运行 → 等待 → 空闲 → 完成/失败/终止；同组按开始时间倒序。
- 描述尾截断；<56 列丢父代理，<48 列丢耗时，<40 列丢类型与「工具」字样。
- 空态：「本会话还没有子代理。」，不画伪造行。

## 详情

安静页：类型、父代理、开始/结束、工具与失败数、最后输出、「对话摘录」。

- 对话摘录按需调用 `$.session.messages({ agentId })`，保留最后 40 行、每行 200 字，超出标「（已截断）」；
- 引擎拒绝读取时写「无法读取该代理的对话」，其余字段仍可读；
- **没有终止、重启或发送消息的按钮**；不 spawn 代理。

## 本迭代不做

- 不杀代理、不重启、不向代理发消息；
- 不做跨会话索引、搜索、云同步；
- 不改变代理执行；花名册计算失败只写日志。
