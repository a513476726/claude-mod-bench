# OpenSpec 变更追踪 - 变更扫描与分段

---

## 1. 功能说明

把工作区各仓库的 OpenSpec 变更按状态分段展示，让你一眼看到每个变更做到哪一步。

### 业务边界

- 负责：扫描进行中与已归档变更、按五种状态分段、折叠与详情（进度、需求号、作者、未完成任务原文）。
- 不负责：修改或归档任何变更文件。
