# OpenSpec 变更追踪

---

## 1. 模块概述

扫描工作区各仓库的 `openspec/changes/`，按状态分段展示每一处变更的进度，点开看任务、需求号与未完成项。

### 业务范围

**负责：**

- 找到要扫描的仓库（与分支区共用发现规则）
- 读取变更目录、`tasks.md`、`proposal.md`
- 分段、排序、折叠、详情

**不负责：**

- 修改或归档变更

### 核心能力

- 单仓库会话与多仓库工作区都能读到变更
- 五种状态的自动归段
- 未完成任务以原文列出

## 3. 核心架构

```text
discoverOf → scan → SpecChange[] → groupOf 分段 → 页面
```

### 前端

OpenSpec 页签：分段标题、列表行、详情页。

### 后端

`hooks/scan.ts` 的 `scan()` / `changeOf()` / `groupOf()`。

### 数据

不落盘；状态是运行期的一组 `SpecChange` 记录。

### 外部依赖

本地文件系统与 `git` 命令。

---

## 4. 核心业务流程

```text
会话启动 / 每轮结束 → 扫仓库 → 读变更 → 分段 → 画列表 → 点开看详情
```

---

## 5. 核心对象

| 对象 | 说明 | 关联功能 |
| --- | --- | --- |
| `SpecChange` | 一处变更的进度、需求号、作者与未完成任务 | 变更扫描与分段 |

---

## 6. 模块级约束

- 与分支区共用仓库发现，不得各写一套。
- 扫描失败时保留上一次的列表，不得显示为空。
