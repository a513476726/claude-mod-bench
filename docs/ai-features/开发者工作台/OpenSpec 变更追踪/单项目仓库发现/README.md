# OpenSpec 变更追踪 - 单项目仓库发现

---

## 1. 功能说明

让 OpenSpec 页签在会话直接开在某个仓库里时也能读到该仓库的变更，而不是一片空白。

### 业务边界

- 负责：会话起始目录即仓库、或位于仓库子目录时，定位到仓库根并扫描其变更。
- 不负责：跨两级以上目录查找、手动指定扫描路径。
