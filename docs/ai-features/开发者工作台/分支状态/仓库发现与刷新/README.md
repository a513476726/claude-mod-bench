# 分支状态 - 仓库发现与刷新

---

## 1. 功能说明

在面板底部告诉你当前所在仓库与各兄弟仓库停在哪个分支、有没有没提交的改动，并在切分支后及时更新。

### 业务边界

- 负责：识别会话自身仓库、工作区根与兄弟仓库并展示分支与未改动数；面板打开期间定时刷新；按文件查看未提交改动（变更 / 整个文件两种视图）。
- 不负责：切换分支、展示提交历史、跨两级以上目录递归扫描、提交或撤销改动。
