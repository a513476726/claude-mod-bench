# 分支状态 - 仓库发现与刷新

---

## 1. 背景与目标

### 1.1 功能描述

面板底部常驻一行分支栏，告诉你「我现在在哪个仓库、它停在哪个分支、有没有没提交的东西」，以及同一工作区里还有哪些仓库、各自停在哪。

### 1.2 使用场景

- 会话直接开在某个仓库根目录（单项目）：需要确认自己没在错的分支上。
- 会话开在一个装着多个仓库的工作区里：需要一眼看到所有仓库的分支。
- 在终端里 `git checkout` 之后、还没发下一句话：需要分支栏尽快追上。

### 1.3 功能范围

**包含：**

- 会话自身所在仓库的分支展示
- 工作区根目录与兄弟仓库的自动发现与展示
- 未提交改动数与「预览」入口
- 面板打开期间的定时刷新

**不包含：**

- 切换分支（只显示，不操作）
- 展示领先/落后提交数、`git log`
- 跨两级以上目录的递归扫描

## 2. 业务流程

```text
会话启动 / 面板打开
    ↓
读取会话起始目录
    ↓
判定起始目录是否「被搁置的空间」（有 .claude/worktrees 或 .git 标记文件）
    ├── 是 → 不读任何仓库
    └── 否
         ↓
    起始目录里是否有仓库 → 是：(1) 起始目录自身是仓库时列第一行 (2) 作为工作区继续找兄弟仓库
                          └ 否：向上最多 2 层找「装着仓库的目录」作为工作区
         ↓
    工作区自身是仓库 → 追加「根目录」行
         ↓
    工作区下每个带 .git 或 openspec/ 的子目录 → 一行，按名称排序
         ↓
    每个仓库读 .git/HEAD 得分支名，跑 git status --porcelain 得改动数
         ↓
    只画分支名非空的仓库
         ↓
    面板打开期间每 5 秒重读一次分支
```

---

## 3. 业务规则

| 规则 | 说明 |
| --- | --- |
| 仓库判定 | 目录下**有 `.git`**（目录，或 worktree/submodule 的 `gitdir:` 指针文件）**或**有 `openspec/`，即视为仓库；不依赖任何仓库名白名单 |
| 工作区判定 | 一个目录「装着仓库」指其下有带 `.git` 或 `openspec/` 的子目录（`node_modules` 不计） |
| 工作区定位 | 起始目录本身装着仓库 → 它就是工作区；否则从上一级起**最多向上 2 层**找第一个装着仓库的目录 |
| 被搁置的空间 | 目录根下存在 `.claude/worktrees` 或 `.git` **文件**（不是目录）时，视为他人搁置的 clone，**不读取其中任何仓库** |
| 排序 | 起始仓库 → 工作区根 → 兄弟仓库（按名称升序） |
| 去重 | 同一路径只出现一次 |
| 分支名 | 直接读 `HEAD` 的 `ref: refs/heads/<name>`；detached HEAD（无 `ref:`）不显示该行 |
| 未提交改动 | `git status --porcelain` 的非空行数 |
| 行数上限 | 最多显示 6 行仓库，超出时末行显示「… 还有 N 个仓库」 |
| 刷新周期 | 面板打开期间每 5000 毫秒重读一次分支 |
| 内容未变不重绘 | 分支与改动数与当前显示一致时不写状态 |

## 4. 权限与状态

### 4.1 权限

| 角色 | 权限 | 说明 |
| --- | --- | --- |
| 使用者 | 查看、预览 diff | 无写操作；点击「预览」在面板内查看该仓库的 `git diff` |

### 4.2 状态

| 状态 | 含义 | 可执行操作 |
| --- | --- | --- |
| 干净 | 改动数为 0，分支名以成功色显示 | 无 |
| 有改动 | 改动数 > 0，分支名以提示色显示，行尾显示 `+N` 与「预览」 | 预览 diff |

---

## 5. 方案要点

### 5.1 前端

面板底部的分支区由 `branchesLine` 绘制：一行一个仓库，`*` 标记根目录行、`|` 标记兄弟仓库行，目录名列 14 列，分支名超宽时保留首尾。根目录行在分支区显示为「根目录」。

### 5.2 后端

`hooks/scan.ts` 的 `discoverOf` 是分支区与 OpenSpec 扫描**共用的唯一仓库发现来源**；`workspaceOf` 负责定工作区与「被搁置」判定；`branchesOf` 对每个仓库调 `branchAt` 与 `changesAt`。

### 5.3 架构 / 依赖

只读本地文件系统与 `git` 命令，不启动常驻子进程。定时刷新依赖引擎的 `$.clock`。

### 7.4 关键字段

分支栏每一行的字段（来自 `Branch` 类型）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 仓库名；根目录行为 `.`（分支区显示为「根目录」） |
| `branch` | string | 是 | `HEAD` 指向的分支名 |
| `changes` | number | 是 | 未提交改动的文件数，0 为干净 |

## 10. 可测验收标准

| 编号 | 前置条件 | 操作 / 触发 | 预期结果 | 优先级 |
| --- | --- | --- | --- | --- |
| AC-01 | 会话开在单个 git 仓库根目录 | 打开面板 | 分支区第一行为「根目录 <当前分支>」 | P0 |
| AC-02 | 会话开在一个装着多个仓库的工作区 | 打开面板 | 工作区根（若为仓库）与各兄弟仓库各一行，按名称排序 | P0 |
| AC-03 | 兄弟目录名不在任何预置名单中，带 `.git` | 打开面板 | 该仓库出现一行 | P0 |
| AC-04 | 某仓库 `git status --porcelain` 返回 3 条 | 打开面板 | 该行分支名为提示色，行尾显示 `+3` 与「预览」 | P0 |
| AC-05 | 面板已打开，未发起任何对话 | 终端执行 `git checkout <新分支>`，等待 5 秒 | 分支区显示新分支 | P0 |
| AC-06 | 会话目录下 `.git` 是 `gitdir:` 指针文件 | 打开面板 | 分支区显示指针指向的 worktree 分支 | P0 |
| AC-07 | 目录根下有 `.claude/worktrees` 文件 | 打开面板 | 该目录内的仓库不出现在分支区 | P1 |
| AC-08 | 工作区下有 8 个仓库 | 打开面板 | 只显示前 6 行，末行显示「… 还有 2 个仓库」 | P1 |
| AC-09 | 某个仓库有未提交改动 | 点该行「预览」→ 进入某文件 | 文件页有两个标签「变更」「整个文件」；「整个文件」显示该文件当前全文，两边可来回切换 | P0 |
| AC-10 | 改动文件名含中文 | 打开 diff 文件列表 | 文件名显示为中文原名（不是 `\345\274` 这类转义），点开能看到内容 | P0 |
| AC-11 | 文件既在工作区改动中又在暂存区 | 打开 diff 文件列表 | 该文件只出现一行 | P1 |
| AC-12 | 新增（未跟踪）文件 | 打开 diff 文件列表 → 点开该文件 | 列出该文件，点开后显示其全文 | P0 |
