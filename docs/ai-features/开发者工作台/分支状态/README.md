# 分支状态

---

## 1. 模块概述

面板底部的常驻分支栏：说明当前在哪个仓库、停在哪个分支、有没有没提交的改动，以及同一工作区里还有哪些仓库。

### 业务范围

**负责：**

- 仓库发现（会话自身仓库、工作区根、兄弟仓库）
- 分支名与未提交改动数的展示
- 面板打开期间的分支刷新

**不负责：**

- 切换分支
- 查看提交历史

### 核心能力

- 按 `.git` / `openspec/` 自动识别仓库，不依赖仓库名名单
- 定时刷新，切分支后无需发对话即可看到

## 3. 核心架构

```text
discoverOf(会话目录)
    ├── workspaceOf：定工作区 / 判定是否被搁置
    ├── 会话自身仓库
    ├── 工作区根（若为仓库）
    └── 兄弟仓库（按名称排序）
         ↓
branchesOf：对每个仓库读 HEAD 与 git status
         ↓
面板底部一行一个仓库
```

### 前端

`hooks/panes.tsx` 的 `branchesLine`：一行一仓库，最多 6 行。

### 后端

`hooks/scan.ts` 的 `discoverOf` / `branchesOf` / `branchAt` / `changesAt`。

### 数据

不落盘；状态是运行期的一组 `Branch` 记录。

### 外部依赖

本地文件系统与 `git` 命令。

---

## 4. 核心业务流程

```text
会话启动 → 读取仓库 → 画分支栏 → 每 5 秒重读 → 有变化才重绘
```

---

## 5. 核心对象

| 对象 | 说明 | 关联功能 |
| --- | --- | --- |
| `Branch` | 一个仓库的分支与改动数 | 仓库发现与刷新 |

---

## 6. 模块级约束

- 仓库发现与 OpenSpec 页签共用，两边不得各自另写一套判定。
- 不维护仓库名白名单。
