# 对话记录

---

## 1. 模块概述

把会话里每一轮对话记成一条可追溯的记录，并在顶部给出整场会话的用量与工具使用全貌，可以逐层点到某一次工具调用。

### 业务范围

**负责：**

- 一轮对话的起点、结束、用量、工具归属
- 会话级的模型用量与工具统计
- 工具调用的逐层下钻

**不包含：**

- 跨会话历史
- 费用金额换算

### 核心能力

- 按模型分组统计 token
- 工具与命令的三层下钻
- 每次工具调用保留参数与结果摘要

## 3. 核心架构

```text
prompt.submit / AskUserQuestion / turn.start  → 开一轮
tool.call                                    → 记到当轮名下 + 保留明细
turn.complete                                → 补全用量、回答、结束原因
         ↓
statsOf 汇总 → 对话页签顶部
```

### 前端

对话页签：顶部统计区、轮次列表、轮次详情（含可点的工具名）、下钻各层。

### 后端

`hooks/conversation.ts`（纯函数）、`hooks/items.ts`（条目生成）。

### 数据

保存在插件的本地状态里；轮次有保留上限。

### 外部依赖

引擎事件与本地状态存储。

---

## 4. 核心业务流程

```text
输入 / 提问 → 开一轮 → 工具调用逐次记录 → 轮次结束补全 → 统计与列表更新
```

---

## 5. 核心对象

| 对象 | 说明 | 关联功能 |
| --- | --- | --- |
| `Turn` | 一轮对话 | 会话用量与工具统计 |
| `ToolNote` | 一次工具调用的明细 | 工具调用下钻 |
| `SessionStats` | 会话级汇总 | 会话用量与工具统计 |

---

## 6. 模块级约束

- 子代理的回合不计入主会话的轮次。
- 明细有容量与截断上限，超出后淘汰最旧记录。
