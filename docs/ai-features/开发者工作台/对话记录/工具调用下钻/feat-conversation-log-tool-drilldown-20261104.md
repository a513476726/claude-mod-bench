# 对话记录 - 工具调用下钻

---

## 1. 背景与目标

### 1.1 功能描述

从「工具有多少次」一层层点到「某一次调用具体执行了什么」：统计 → 工具分组 → 该工具的每次调用 → 单次调用的完整参数与结果。

### 1.2 使用场景

- 复盘一轮里 `Bash ×3` 分别跑了哪三条命令。
- 确认某次 `Skill` 调用加载的是哪个技能。
- 排查某次工具调用为什么失败。

### 1.3 功能范围

**包含：**

- 统计区的「工具」「命令」两个入口
- 工具分组列表、单工具的全部调用
- 轮次详情里按工具名下钻到该轮的逐次调用
- 单次调用的参数与结果页

**不包含：**

- 修改或重放任何调用
- 跨会话检索历史调用

---

## 1.5 返回

所有下钻层与详情共用**内容区右上角**的「← 返回」，`b` 键等价：

- 下钻层 → 上一层；
- 列表的详情 → 该列表；
- 最外层（页签自己的列表）不显示返回。

OpenSpec 详情、分支 diff 的文件列表与单文件、宠物详情用的是同一个按钮。

## 2. 业务流程

```text
对话页签
    ├── 点「工具 N 种 · M 次」 → 工具分组（按次数降序）
    │       └── 点某工具 → 该工具的全部调用（最新在前）
    │               └── 点某次 → 完整参数与结果
    │                       └── 返回 → 调用列表 → 工具分组 → 对话列表
    ├── 点「命令 K 次」 → 每次 Bash 的命令原文 → 完整参数与结果
    └── 点开某轮 → 点工具名（如 Bash ×2）→ 该轮该工具的逐次调用 → 单次
```

---

## 3. 业务规则

| 规则 | 说明 |
| --- | --- |
| 记录时机 | 每次工具调用发生时记到「当时正在进行的那一轮」名下 |
| 逐次保留 | 每个工具名最多保留最近 50 条调用记录，超出的最旧的淘汰 |
| 摘要截断 | 每条摘要最多 200 字，参数最多 2000 字，结果最多 400 字 |
| 摘要内容 | `Bash` 取命令原文；`Skill` 取技能名；其他取「工具名 · 第一个参数」 |
| 归属 | 不属于任何进行中轮次的调用不记入对话 |
| 下钻层级 | 至少三层：统计 → 工具/命令分组 → 单次调用 |
| 返回 | 逐层退回；切换到其他页签、打开行详情时，下钻路径清空 |
| 空态 | 无工具调用 →「本次会话没有调用工具」；无命令 →「本次会话没有执行命令」 |

### 4.1 权限

| 角色 | 权限 | 说明 |
| --- | --- | --- |
| 使用者 | 查看 | 只读 |

### 4.2 状态

无业务状态；界面有「下钻层级」状态（记录当前处在第几层）。

---

## 5. 方案要点

### 5.1 前端

下钻路径存放在视图状态里（一层一个 id，空表示回到页签自己的列表）。每层是一组可点条目；最后一层是只读详情，`b` 或「← 返回」逐层退回。轮次详情底部把工具名渲染为可点按钮，文案保持 `Read ×2 · Bash ×1`。

### 5.2 后端

`hooks/conversation.ts` 的 `attachTool` 在计数之外保留每次调用的明细；`hooks/items.ts` 的 `drillItemsOf` / `callDetailOf` 生成每一层的条目与单次详情。

### 5.3 架构 / 依赖

数据只在本地状态里，不落盘。

---

## 6. 影响范围

- 对话页签的下钻交互
- 轮次详情底部的工具行
- `decisions` 状态的容量（每轮每工具最多 50 条明细）

### 6.2 兼容性

`decisions` 状态形状升级，升级前的轮次没有明细，点开后为空。

---

## 7. 接口设计

无 HTTP 接口。

### 7.4 关键字段

单次调用记录（来自 `ToolNote`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `at` | number | 是 | 调用开始时间（epoch ms） |
| `ms` | number | 是 | 耗时，`-1` 表示未知 |
| `isOk` | boolean | 是 | 是否成功 |
| `summary` | string | 是 | 一行摘要 |
| `detail` | string | 是 | 完整入参（截断到 2000 字） |
| `result` | string | 是 | 结果文本（截断到 400 字） |

## 10. 可测验收标准

| 编号 | 前置条件 | 操作 / 触发 | 预期结果 | 优先级 |
| --- | --- | --- | --- | --- |
| AC-01 | 一轮里 Bash 被调用两次（`git status`、`npx tsc`） | 点开该轮后点 `Bash ×2` | 列出两条，摘要分别为两条命令原文 | P0 |
| AC-02 | 同上 | 再点第一条 | 显示该次调用的完整参数与结果 | P0 |
| AC-03 | 在单次调用页 | 按 `b` | 回到调用列表；再按 `b` 回到轮次详情 | P0 |
| AC-04 | 本会话调用过 `Bash` 5 次、`Read` 3 次 | 点统计区的工具入口 | 显示 `Bash 5 次`、`Read 3 次`，按次数降序 | P0 |
| AC-05 | 本会话没有执行过命令 | 点统计区的命令入口 | 显示「本次会话没有执行命令」 | P1 |
| AC-06 | 一轮里 `Skill` 被调用两次（`openspec-propose`、`feature-doc-regression`） | 点开 `Skill ×2` | 两条分别标出所加载技能名 | P0 |
| AC-07 | 同一工具被调用 60 次 | 查看该工具调用列表 | 只保留最近 50 条 | P1 |
| AC-08 | 命令长度超过记录上限 | 查看该次调用 | 摘要被截断并带省略号，参数保留到上限 | P1 |
| AC-09 | 任意详情或下钻层 | 查看内容区右上角 | 有且只有一个「← 返回」按钮，`b` 键等价 | P0 |
| AC-10 | 处在最外层对话列表 | 查看内容区 | 不显示返回按钮 | P1 |
