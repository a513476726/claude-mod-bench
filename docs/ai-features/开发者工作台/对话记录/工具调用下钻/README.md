# 对话记录 - 工具调用下钻

---

## 1. 功能说明

从「工具有多少次」一层层点到「某一次调用具体执行了什么」。

### 业务边界

- 负责：统计入口 → 工具/命令分组 → 每工具的逐次调用 → 单次调用的完整参数与结果。
- 不负责：修改或重放调用、跨会话检索历史调用。
