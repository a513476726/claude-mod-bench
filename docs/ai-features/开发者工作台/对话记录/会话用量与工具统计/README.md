# 对话记录 - 会话用量与工具统计

---

## 1. 功能说明

在对话页签顶部给出整场会话花了多少 token、调了多少次工具和命令。

### 业务边界

- 负责：按模型分组的四项 token 与合计、工具种类与总次数、命令次数。
- 不负责：跨会话累计、费用金额换算、子代理单独统计。
