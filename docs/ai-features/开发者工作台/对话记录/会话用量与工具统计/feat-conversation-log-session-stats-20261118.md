# 对话记录 - 会话用量与工具统计

---

## 1. 背景与目标

### 1.1 功能描述

对话页签顶部给出整场会话的用量与工具使用全貌：每个模型花了多少 token、一共调了多少次工具、跑了多少条命令；并显示当前上下文占用（`CTX`），帮助判断何时压缩或清理上下文。

### 1.2 使用场景

- 长会话结束时复盘「这次花了多少、主要花在哪个模型上」。
- 想快速确认「这次会话主要在用哪些工具」。
- 干活过程中判断上下文是否快满、是否需要压缩或清理。

### 1.3 功能范围

**包含：**

- 按模型分组的输入 / 输出 / 缓存读 / 缓存写 token 与合计（下钻页），数字使用 K / M 单位
- 工具种类数与总调用次数、命令（`Bash`）执行次数
- 当前上下文占用百分比 `CTX`：对话统计行行尾、面板上方常驻横条
- `CTX` 按 70% / 90% 两个阈值着色

**不包含：**

- 跨会话累计（只统计当前保留的轮次）
- 费用金额换算
- 子代理单独统计
- 自动压缩 / 清理上下文、文字提醒或按钮
- 按模型分别计算上下文百分比（`CTX` 是会话级、最近一次响应的读数）

---

## 2. 业务流程

```text
读取本会话保留的轮次
    ↓
逐轮取 token 用量（模型、输入、输出、缓存读、缓存写）
    ↓
按模型分组求和，再求全部合计（显示为 K / M）
    ↓
读取引擎的会话测量：最近一次响应的输入侧 token / 模型真实窗口
    ↓
计算 CTX 百分比（向下取整）
    ↓
画在对话页统计行行尾；AbovePrompt 横条也常驻显示（面板关闭时仍可见）
    ↓
逐轮取工具调用（按工具名计次）
    ↓
汇总工具种类数、总次数、Bash 次数
```

---

## 3. 业务规则

| 规则 | 说明 |
| --- | --- |
| 统计范围 | 仅统计当前 `turns` 中保留的轮次；超出保留上限被淘汰的轮次不计入 |
| 轮数口径 | 统计行的「N 轮」与按模型分组的轮数只计**上报了用量**的已结束轮次；中断 / 报错等未报用量的轮次不计入轮数与模型分组，但其工具调用仍计入工具统计 |
| 模型分组 | 按 `usage.model` 分组，同一模型的多个轮次求和，按轮数降序 |
| 未报模型 | `usage.model` 为空时归为「未知模型」 |
| 无用量 | 没有任何轮次上报用量时显示「（暂无用量）」 |
| 数字单位 | 小于 1000 原样显示；1000–999 999 显示整数 `K`；1 000 000 及以上显示一位小数 `M`；一律向下取整（`999 999` → `999K`，`1 200 000` → `1.2M`） |
| 上下文来源 | 取引擎的会话测量（与状态行同源），不由对话轮次用量累加；口径是最近一次 API 响应的输入侧（未缓存输入 + 缓存读 + 缓存写） |
| 上下文分母 | 该模型真实的上下文窗口大小，不是固定值 |
| 上下文百分比 | `floor(输入侧 token ÷ 窗口 × 100)`，向下取整；超过 100 时原样显示（如 `CTX 103%`） |
| 上下文更新 | 每次主线程轮次结束时随引擎测量更新；压缩（compaction）后自动回落 |
| 无读数 | 引擎尚未给出输入 token 时（新会话、刚压缩完）显示 `CTX —`，不显示 `0%` |
| 颜色阈值 | 低于 70% 默认灰；70% 起 `warning`；90% 起 `error`；只有颜色，没有文字提醒 |
| 展示位置 | 对话统计行行尾 `· CTX 62%`；AbovePrompt 末尾 `\| CTX 62%`；「会话」下钻页不出现百分比 |
| 窄屏 | 统计行放不下时先丢 `CTX`，再放不下才把「缓存读 / 缓存写」缩写为「读 / 写」；仍放不下时截断行尾，不换行。横条先丢 `MCP`、再丢「对话」，`CTX` 最后才丢；`CTX` 不可点 |
| 工具种类 | 不同工具名的个数 |
| 命令次数 | 工具名为 `Bash` 的调用次数 |
| 空工具 | 无工具调用时显示「工具 0 种 · 0 次」 |
| 小面板 | 面板高度小于 20 行时只显示会话统计行（含 `CTX`），工具 / 命令行隐藏 |

## 4. 权限与状态

### 4.1 权限

| 角色 | 权限 | 说明 |
| --- | --- | --- |
| 使用者 | 查看 | 只读 |

### 4.2 状态

无独立状态。`CTX` 的显示颜色随占用变化：默认灰 / `warning` / `error`。

---

## 5. 方案要点

### 5.1 前端

对话页签顶部是一行会话统计摘要：`会话` 标签 + 轮数、模型数 + 四项 token（K / M）+ 行尾 `· CTX n%`。第一行摘要本身可点，进入按模型下钻页；面板高度足够时第二行是「工具 N 种 · M 次」与「命令 K 次」，两项同样可点下钻。每模型的四项明细在下钻页，只做 K / M 格式化，不带百分比。

同一份 `CTX` 也出现在面板上方的常驻横条末尾（`| CTX n%`），面板关闭时仍可见；横条宽度不足时先丢 `MCP`、再丢「对话」，`CTX` 最后丢，且不可点击。

### 5.2 后端

`hooks/conversation.ts` 的 `statsOf(turns)` 汇总四项与工具计数；`hooks/format.ts` 的 `kmOf` 负责 K / M 格式化、`ctxOf` 负责百分比与颜色；`hooks/items.ts` 生成下钻行；`hooks/panes.tsx` 绘制统计行并做宽度取舍；`hooks/register.tsx` 维护 `ctx` 状态（`session.start` 初始化、`session.measure` 推送、`turn.complete` 兜底重读）并绘制 AbovePrompt。

### 5.3 架构 / 依赖

不依赖网络。上下文读数来自引擎的 `session.usage()` / `session.measure`，与 Claude Code 状态行同源；其余数据来自本地保留的轮次记录。

---

## 6. 影响范围

### 6.1 受影响角色 / 页面 / 服务

- 对话页签的统计行与按模型下钻页
- 面板上方 AbovePrompt 横条
- 对话页列表的可见行数（统计行占用）

### 6.2 兼容性

- 新增 `ctx` 状态（shape `ctx-1`）；旧值在升级时丢弃。
- 其它页签与轮次详情不受影响；单轮详情「用量」仍是精确 token。

## 7. 接口设计

无 HTTP 接口。

### 7.4 关键字段

统计结果字段（来自 `SessionStats`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `models[].model` | string | 是 | 模型 id |
| `models[].turns` | number | 是 | 该模型**上报了用量**的轮数 |
| `models[].input/output/cacheRead/cacheWrite` | number | 是 | 四项 token 之和 |
| `total` | object | 是 | 全部模型的四项合计 |
| `toolKinds` | number | 是 | 不同工具名的个数 |
| `toolCalls` | number | 是 | 工具调用总次数 |
| `commandCalls` | number | 是 | `Bash` 调用次数 |

上下文读数（来自引擎会话测量，存为 `ctx`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `tokens` | number | 否 | 最近一次响应的输入侧 token；缺失表示尚无读数 |
| `window` | number | 是 | 当前模型的上下文窗口 |

## 8. 数据库设计

无。

---

## 9. 缓存 / 消息队列 / 异常

无缓存与消息队列。

- 引擎不提供会话用量时（旧宿主或调用失败），`CTX` 显示 `—`，不影响统计行其余内容与面板绘制。
- 会话测量更新时若读数未变化，不重复写入状态。

## 10. 可测验收标准

| 编号 | 前置条件 | 操作 / 触发 | 预期结果 | 优先级 |
| --- | --- | --- | --- | --- |
| AC-01 | 四项分别为 999、120 400、999 999、25 200 000 | 打开对话页签 | 依次显示 `999`、`120K`、`999K`、`25.2M` | P0 |
| AC-02 | 最近一次响应输入侧 620 000，窗口 1 000 000 | 打开对话页签 | 统计行显示 `CTX 62%`，不因历史轮次累计而变大 | P0 |
| AC-03 | 占用 62% / 70% / 90% | 查看统计行与横条 | 依次为默认灰 / `warning` / `error` | P0 |
| AC-04 | 新会话或刚压缩完，无输入 token | 打开对话页签 | 显示 `CTX —`，不显示 `0%` | P0 |
| AC-05 | 已有一轮用量 | 点统计行进入「会话」下钻页 | 每行与合计用 K / M，页面不出现 `%` | P0 |
| AC-06 | 面板宽度依次为 100 / 72 / 60 / 40 列 | 查看统计行 | 100 保留 CTX；72 丢 CTX 仍用「缓存读」；60 缩写为「读/写」；40 截断且不换行 | P0 |
| AC-07 | 面板关闭，读数 62% | 查看 AbovePrompt 横条 | 末尾显示 `| CTX 62%`；窄屏先丢 MCP / 对话；点击无反应 | P0 |
| AC-08 | 会话调用 Bash 5 次、Read 3 次、Write 1 次 | 打开对话页签 | 显示「工具 3 种 · 9 次」「命令 5 次」 | P0 |
| AC-09 | 会话刚开始，无已结束轮次 | 打开对话页签 | 统计行显示「（暂无用量）」，工具行显示「工具 0 种 · 0 次」 | P0 |
| AC-10 | 面板高度 12 行 | 打开对话页签 | 只显示统计行（含 CTX），工具 / 命令行隐藏 | P1 |
| AC-11 | 两个模型分别为 2 轮与 1 轮 | 点统计行进入「会话」下钻页 | 两行模型 + 合计，合计等于各模型之和，轮数只计上报了用量的轮次 | P0 |
