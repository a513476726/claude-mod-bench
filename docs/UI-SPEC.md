# bench UI 规范 · 方向 D（状态优先 / 平铺）

> Claude Code 开发者面板的界面契约。方向 D 的核心是一句话：**状态是第一列，不是整行底色；结构靠规则线与缩进，不靠卡片。**
>
> 视觉参考：`design/visual-reset.html` 的 D 标签页（列表 / 详情 / 80 / 64 / 40 列）。
>
> **分层**：§1 是引擎强加的硬约束（违反即加载失败或错位）；§2 起是方向 D 的项目决策（可迭代，改动必须同步本文与 `bench-ui`）。

---

## 0. 定位与原则

1. **一屏一页，一页一条流。** 列表页只有一个主内容区；详情页是安静页。没有卡片、没有卡片套卡片、没有分组标题占行。
2. **状态是列，不是底色。** 每条记录的第一列是 2 字状态标签；颜色只落在这一列和状态筛选轨道上，行内其余文字保持灰阶。
3. **结构只靠规则线与缩进。** 整宽 `─` 线分段，2 格缩进表示层级；不画左右竖线，不画圆角边。
4. **颜色是词，不是背景。** 一屏最多 5 个状态标签色，但它们共享同一列、同一语义；不允许整行上色，不允许彩色背景块。
5. **文字优先，符号最小。** 用「进行 / 待办 / 异常 / 完成 / 无单」代替 `* o ! + .`；用 `▸` 表示光标；用 `*` / `|` 表示分支归属。**面板内不使用 emoji。**
6. **详情是安静页。** 打开详情后没有页签、没有筛选轨道、没有分支轨道；只有标题、状态标签、字段、正文与右上角返回。
7. **构件优先。** 规则线、标签列、筛选轨道、分支轨道、页头、字段行只能来自 `hooks/ui.tsx`；页面不得自绘边框、补空格或挑颜色。
8. **暗色优先。** 默认暗色主题可读；亮色主题只允许通过主题令牌反转，不硬编码颜色。

**定位**：一行一件事，固定列，`git log --oneline` 的密度 + 状态列的可扫读性，装进一张没有边框的页面。

## 1. 引擎约束（不可协商）

以下来自 `claude-code` 类型文件与本机实测。违反会直接出问题，不是风格偏好。

### 1.1 字符宽度

| 约束 | 说明 |
|---|---|
| **禁用 East Asian Ambiguous 字符** | `●` `○` `★` `⚠` `▶` `▼` `■` `◆` `·` 在 CJK 终端可能占 2 格。`·` 仅允许出现在非对齐的散文/页脚，不进入列数据。 |
| **不使用 emoji** | 方向 D 不再使用 emoji，包括页签、卡片标题、字段标签、分区标题。emoji 宽度在 kitty/tmux 下不一致，且会把列宽算错。 |
| **禁用 Nerd Font 图标** | 用户未装字体即成豆腐块，且无法探测。 |
| **安全符号集** | 见 §6。方向 D 只保留 `─` `▸` `*` `|` `←` `↑↓` `…` 与中文/ASCII。 |
| **中文占 2 格** | 任何补空格、算宽度都必须按显示宽度而非字符数；只用 `cellsOf` / `padCells`。 |
| **Box Drawing 只用于整宽规则线** | 只允许 `─` 作为页内横线；不使用 `╭ ╮ ╰ ╯` 与 `│` 画卡片/竖边。分支轨道的 `|` 是 ASCII，不是 Box Drawing。 |

### 1.2 组件能力边界

| 组件 | 能做 | 不能做 |
|---|---|---|
| `Button`（默认） | 带 `[ label ]` 边框、`variant="primary"` 强调、`hotkey` | 自定义颜色；去掉边框 |
| `Button`（`plain`） | 无边框、children 任意树、children 内 `Text` 可上色 | `hotkey` 会渲染成 `1: label` 前缀 |
| `Text` | `color` / `backgroundColor` / `weight` / `dimColor` / `wrap` / `tabular` | — |
| `Box` | `flexDirection` / `flexGrow` / `padding` / `borderStyle` / `gap` | **`marginTop` 在 Pane 内不生效** |

**结论**：
- `plain` Button 的 children **只能是字符串与 `Text`**：放 `<Box>` 或 fragment 会让整页绘制失败（`holds strings and Text, not <Box>`）。
- 列表行、状态筛选、分支行、详情返回**必须用 `plain`**，且不带 `hotkey`。
- 页签是唯一例外：未选中页签用**默认 Button** 获得 `[ ]` 与数字热键；选中页签用 `plain`，不再画 `◉`。
- 需要数字热键又不想出现 `1:` 前缀，只能接受未选中页签的 `[ ]`；这是方向 D 唯一保留的方括号。

### 1.3 布局

| 约束 | 说明 |
|---|---|
| 引擎放置下限 **110 列**（实测 v2.1.317，`unasked below 110 columns`） | ≥144 列停靠在对话上方、聊天同屏；110 列已放置但占满窗口；<110 列不自动停靠，状态行提示「面板未停靠」，`/panel` 仍可打开（40 列实测切紧凑标签）。 |
| 主动 `/panel` 在窄屏仍可打开 | 只是不常驻：`isPlaced: false` 时写 `.bench-dock.txt` 并在状态行说明原因。 |
| 主屏模式（tmux / `NO_FLICKER=0`）**不 dock 面板** | 宽度再大也无用。 |
| 列宽优先级（Ratatui 标准） | `Min > Max > Length > Percentage > Ratio > Fill`。 |
| **只留一个 Fill 列** | 多个弹性列会互相挤压；`Length` + `Percentage` 混合时 Percentage 列会被挤到 0。 |
| Pane 高度 | `e.props.scroll.bodyRows`；不是 `e.props.bodyRows`。 |
| 焦点 | `focus` 是请求不是保证；`hotkey` 只在面板持焦点时生效。 |

| 区域 | 行数 | 规则 |
|---|---|---|
| 页签 | 1 | 无 emoji；选中 accent + bold；未选中 `[ ]` + 数字热键 |
| 规则线 | 1 | 整宽 `─`，`INK.frame` |
| 状态轨道 / 统计轨道 | 1–2 | OpenSpec 状态筛选；对话统计；MCP 服务器；提示音开关说明 |
| 次要筛选 | 1 | OpenSpec 的仓库/时间；始终可见，紧凑 |
| 规则线 | 1 | 整宽 `─` |
| 列表行 | N | 平铺，无分组标题 |
| 规则线 | 1 | 整宽 `─` |
| 页脚 | 1 | `可见/总数 项 · 点行看详情` + 右侧键位 |
| 分支轨道 | 0–4 | 无卡片；最多 3 个仓库 + 「还有 N」 |

**规则**：
- 所有行宽度恒为 `bodyColumns`；没有卡片、没有左右竖线、没有圆角。
- 区域之间用整宽规则线，不用空行堆叠；只在详情正文的段落之间允许 1 行空行。
- 页签与详情互斥：进入详情、下钻、diff、文件、全文页后，页签、状态轨道、分支轨道全部消失。

### 2.2 安静详情页（无页签）

```
  detail-page-scroll-and-full-text                         ← 返回
  进行                                          38/40
────────────────────────────────────────────────────────────────────
仓库    bench

1. 真实终端（小高度、80 / 40 / 24 列、暗/亮主题）逐页滚到底……
2. 若 9.1 发现浮层不可点或压字不可读，按 design.md Decision 1 升级……
```

| 区域 | 规则 |
|---|---|
| 标题 | 完整标题，按宽度折行；第一行右侧为返回按钮预留 `BACK_ROOM`（10 格）；**不得截断** |
| 状态行 | 左：状态标签（有色）；右：进度/时间/次数（muted）；放不下先丢右侧 |
| 规则线 | 整宽 `─` |
| 字段 | 标签列 8 格（<56 列 6 格），纯文本、无 emoji；值折行，续行同一列起 |
| 正文分区 | 1 行空行 + 分区标题（accent）+ 正文缩进 2；不用 `▏` |
| 返回 | 浮在视口右上角，`top = scroll.offset`，右距 3 格，文案 `← 返回`，热键 `b` |
| 滚动提示 | 内容超屏时右下角；`第 N/M 行 · ↑↓ 滚动`，<28 列用 `N/M` |

**详情页是独立页面**：没有页签、没有状态轨道、没有分支轨道。打开详情是为了读一件事，任何横向入口都会分走正文空间。

### 2.3 安静全屏页

输入全文 / 回答全文 / 文件 / diff / 下钻 / 调用详情都属于安静页：

```
  输入全文                                               ← 返回
────────────────────────────────────────────────────────────────────
（正文全文；每行只保留左侧 2 格，不补右侧空白）
```

- 没有页签、状态行、分支轨道。
- 正文每行只保留左侧 `SP.inline`，行尾不补空格，避免序列化体积撑爆引擎。
- 超过显示预算时末尾写「… 还有 N 行未显示（达到显示上限）」。

## 3. 间距、宽度、高度

### 3.1 间距令牌

| 令牌 | 值 | 用于 |
|---|---|---|
| `SP.inline` | 2 | 页面左右缩进；列表行首缩进；字段/正文缩进 |
| `SP.group` | 2 | 同一行内两列之间 |
| `SP.section` | 1 | 详情正文段落之间的空行 |

**禁止**：任意字面量间距、`marginTop`、按 `padding` 猜测宽度。页面不写 `' '.repeat(...)` 拼列，列宽只来自 `lineOf` / `widthsOf`。

### 3.2 列

- 页面内容宽 = `bodyColumns`（没有卡片内宽）。
- 所有列左对齐；只有一个 `Fill` 列，且必须最后。
- 列定义只有一处（`panes.tsx` 的 `LIST_COLS` / `CONV_COLS` / `MCP_COLS` / `SOUND_COLS`），表头（如有）与数据行同出这一处。
- 列与列之间固定 `SP.group`（2 格）；行首固定 `SP.inline`（2 格）。

### 3.3 高度预算

**列表页**：

```
列表可见行 = bodyRows
           − 页签 1
           − 规则线 1
           − 状态/统计轨道（1 或 2）
           − 次要筛选 1（仅 OpenSpec）
           − 规则线 1
           − 规则线 1（页脚上方）
           − 页脚 1
           − 分支轨道（0 到 4）
```

分支轨道行数：

```
n = 仓库数
branchRows = n === 0 ? 0 : min(n, 3) + (n > 3 ? 1 : 0)
```

- 列表可见行 `< 2` 时 MUST NOT 手工切片，交给引擎滚动。
- 「… 还有 N」的 N = 总数 − 实际展示数。
- 加任何固定行（统计、筛选、分支）都必须同步减 `room`。

**详情页**：

```
正文可见行 = bodyRows
           − 标题行数（1 到 3）
           − 状态行 1
           − 规则线 1
           − 字段行数
           − 分区标题与正文行数
```

返回按钮与滚动提示是绝对定位，不占预算。

### 3.4 最小高度

| bodyRows | 行为 |
|---|---|
| ≥ 20 | 正常：状态轨道 1 行、统计 2 行、分支最多 3 行 |
| 12–19 | 统计轨道压到 1 行；分支最多 2 行；页脚保留 |
| < 12 | 只保留页签、状态轨道、列表、页脚；分支轨道隐藏；详情保留标题、状态、字段 |

## 4. 构件规范

每个构件给：**结构 / 变体 / 尺寸 / 颜色 / 反例**。页面只能组合这些构件。

### 4.0 共用构件

| 构件 | 职责 | 约束 |
|---|---|---|
| `SP` / `INK` / `Tone` | 间距 / 灰阶 / 状态色 | 唯一来源 |
| `STATUS_TAG` | 状态 → 全称 / 2 字 / 1 字 / 色 | 唯一状态词表 |
| `ruleOf(columns)` | 整宽 `─` 规则线 | 输出恒为 `columns` 格 |
| `rowOf(line, columns)` | 平铺行：左侧 2 格 + 内容 + 右侧补齐 | 输出恒为 `columns` 格 |
| `lineOf` / `widthsOf` | 列定义渲染 | 单 `Fill` 列且最后 |
| `footerOf(left, right, columns)` | 页脚两端对齐 | — |
| `pageTitleOf(...)` | 详情标题折行 + 返回预留 | 不截断 |
| `tagWidth(columns)` | 状态标签列宽（5 / 2） | — |

### 4.1 TabBar 页签栏

**结构**：

```
  OpenSpec      对话    MCP    提示音   其他
  ↑ 选中：plain + accent + bold       ↑ 未选中：默认 Button + dimColor
```

| 状态 | 实现 | 外观 |
|---|---|---|
| 选中 | `plain` Button + `<Text color="claude" bold>OpenSpec</Text>` | accent + bold，无括号、无 `◉`、无热键编号 |
| 未选中 | 默认 Button + `hotkey` + `dimColor` | `[ 对话 ]` 括号是引擎唯一的热键渲染 |

**规则**：
- 标签固定：`OpenSpec` / `对话` / `MCP` / `提示音` / `其他`；**不带 emoji**。
- 选中态**不用背景色**；只用前景 accent + bold。
- 页签为 5 个；按 `1`–`5` 切换。
- <56 列时，未选中页签去掉括号与热键，只保留文字（点击切换）；<40 列再改用短名。选中仍为 accent + bold。
- 页签右侧可放一个总数 `14 项`（muted），不参与点击。

**反例**：❌ 用背景色做选中 ❌ 用 `◉` / emoji ❌ 选中态显示 `1:` ❌ 超过 5 个页签。

### 4.2 StatusRail 状态筛选轨道（OpenSpec）

**结构**：

```
 全部 14   进行 3   待办 2   异常 1   完成 7   无单 1
```

| 部分 | 规则 |
|---|---|
| 项 | `全部` + 5 个状态；每项是 `plain` Button，整项可点 |
| 计数 | 紧跟标签，1 个空格；muted；不参与点击 |
| 颜色 | 状态标签用 `STATUS_TAG.tone`；`全部` 选中时 body + bold |
| 选中 | 当前状态 bold；不改变背景；`全部` 是默认 |
| 顺序 | `全部 → 进行 → 待办 → 异常 → 完成 → 无单` |
| 宽度 | 一行；超出时从右侧丢弃低优先级状态，**永不换行** |
| 窄屏 | <56 列用紧凑形式 `全部14 进行3 待办2 异常1 完成7 无单1` |
| 点击 | 选中状态 → 列表只显示该状态；点 `全部` 清除 |

**优先级**（从右往左丢）：`无单 → 完成 → 待办 → 异常 → 进行 → 全部`（`全部` 最后丢，保证始终有清除入口）。

**反例**：❌ 每个状态占一行 ❌ 状态之间加空行 ❌ 整行取状态色 ❌ 计数右对齐 ❌ 换行。

### 4.3 SecondaryFilter 次要筛选（OpenSpec）

**结构**：

```
 仓库 全部 · 时间 全部
 仓库 old_sales · 时间 近 7 天        清除
```

| 部分 | 规则 |
|---|---|
| 仓库 | `全部` 与扫描到的仓库之间循环 |
| 时间 | 全部 → 今天 → 近 7 天 → 近 30 天 循环 |
| 生效 | 非「全部」的值用 accent；未生效项 muted |
| 清除 | 任一筛选生效时出现；点它回到全部 |
| 位置 | 状态轨道下一行，muted，1 行；<56 列压缩为 `仓库全 时间全` |
| 保留 | 切换页签、进详情再返回，筛选值不丢 |

**为什么保留这一行**：状态轨道是方向 D 的主筛选，但仓库/时间是既有能力；把它降为一行安静文字，既保留功能，也不破坏平铺页的简洁。

**反例**：❌ 做成卡片 ❌ 占两行 ❌ 把筛选项塞进状态轨道导致轨道换行。

### 4.4 ListRow 列表行（OpenSpec）

**结构**：

```
▸ 进行  38/40  00d  bench         detail-page-scroll-and-full-text
  进行  13/16   6d  old_sales     fix-signmanager-full-down-payment
```

**列定义**（一个表，表头与数据行同出）：

| 列 | 宽 | 对齐 | 内容 |
|---|---|---|---|
| `cur` | 2 | 左 | `▸ ` 或 `  `；仅选中行显示 |
| `tag` | 5 / 2 | 左 | 2 字状态标签；<48 列用 1 字 |
| `done` | 6 | 左 | `38/40` 或 `—` |
| `age` | 5 | 左 | `00d` / `6d` / `刚刚`；<56 列丢弃 |
| `repo` | 14 | 左 | 仓库名；<64 列丢弃 |
| `name` | Fill | 左 | 变更名；尾截断（唯一允许截断的列） |

**行规则**：
- 行 = `SP.inline` + `cur` + gap + `tag` + gap + `done` + gap + `age` + gap + `repo` + gap + `name`；补齐到 `bodyColumns`。
- 状态标签是**行内唯一带色元素**；`done` / `age` / `repo` 用 `INK.muted`；`name` 用正文色。
- 选中行：`▸` accent + `name` bold；**不改背景、不改 tag 颜色**。
- 整行是 `plain` Button，无 `hotkey`；`label` 为整行文字（无障碍名）；点击进详情。
- 不再有 `*` / `!` / `◆` 等行首标记；状态由 tag 列表达。
- 不再有「最新」标记；同一状态内按修改时间降序，最新自然在最上面。

**状态标签表**：

| 状态 | 2 字 | 1 字 | 色 |
|---|---|---|---|
| 进行中 | 进行 | 进 | `claude` |
| 待归档 | 待办 | 待 | `warning` |
| 归档异常 | 异常 | 异 | `error` |
| 已归档 | 完成 | 完 | `success` |
| 无任务清单 | 无单 | 无 | `subtle` |

**反例**：❌ 整行取状态色 ❌ 用 `* o ! + .` 代替标签 ❌ 状态标签放进行尾 ❌ 多个 Fill 列 ❌ 列宽随内容浮动 ❌ 行首 emoji。

### 4.5 Footer 页脚

**结构**：

```
14/14 项 · 点行看详情                        1–5 页签 · 点状态筛选
```

| 部分 | 内容 | 颜色 |
|---|---|---|
| 左 | `可见/总数 项 · 点行看详情` | `INK.muted` |
| 右 | `1–5 页签 · 点状态筛选`（OpenSpec）或 `1–5 页签` | `INK.muted` |

**规则**：
- 左侧显示 `可见/总数`，不能只显示总数。
- 右侧最多两组提示，不放假按钮。
- 方向 D 不再有 `z 折叠`；分组折叠能力已移除。
- <40 列右侧缩为 `1–5`；左侧缩为 `12/14`。

**反例**：❌ 只显示总数 ❌ 同时出现 `z 折叠` 与状态筛选 ❌ 页脚塞满操作。

### 4.6 BranchRail 分支轨道

**结构**：

```
分支  * 根目录        main                                +3  预览
      | old_sales     develop_20_20261021084
      | sales-platform develop_20_20261012001             +1  预览
```

| 部分 | 规则 |
|---|---|
| 容器 | **无卡片**；第一行以 `分支` 标签起头；不画上下边 |
| 根仓库 | `*`，accent；名称 muted；分支正文色 |
| 子仓库 | `|`，frame 色；名称 muted；分支正文色 |
| 名称列 | 14 格（<56 列 9 格），中截断 |
| 分支列 | 剩余宽度；保留首尾（前缀 + `…` + 末 7 位） |
| 脏工作区 | `+N`，warning；行尾 `预览` 按钮（dimColor），打开该仓库 diff |
| 干净工作区 | 不出现任何彩色；无 `预览` |
| 上限 | 最多 3 个仓库行（<40 列 1 行）；超出时末行 `… 还有 N 个仓库` + `查看全部`（展开后 `收起`） |
| 高度 | `n=0 → 0`；`n>0 → min(n,3) + (n>3 ? 1 : 0)` |
| 窄屏 | <56 列：名称 9 格、分支保留末 7 位；`预览` 只在该行放得下时出现 |
| 刷新 | 会话启动、每轮结束、面板打开期间每 5 秒（`BRANCH_POLL_MS`）；签名未变不重绘 |

**为什么保留逐仓一行**：`develop_20_20261012001` 与 `develop_20_20261021084` 前 20 位相同，只截尾无法区分；一仓一行才能保留末 7 位。方向 D 去掉的是卡片，不是这一行的必要性。

**反例**：❌ 分支做回卡片 ❌ 全部横排成一行 ❌ 干净分支上绿色 ❌ 每个仓库用不同颜色。

### 4.7 StatsRail 统计轨道（对话）

**结构**：

```
 工具  5 种 · 42 次       命令 17 次
```

| 部分 | 规则 |
|---|---|
| 容器 | 无卡片；2 行（`bodyRows < 20` 时 1 行）；下面接规则线 |

### 4.9 PageHead 详情页头

**结构**：

```

  进行                                          38/40
```

| 部分 | 规则 |
|---|---|

### 4.10 详情分区

| 页面 | 标题 | 状态行 | 字段 / 分区 |
|---|---|---|---|
| OpenSpec 变更 | 变更名 | `进行` + `38/40` | 仓库/状态/任务/需求号/开发/文件/修改；`未完成` 任务 |
| 对话一轮 | 输入第一行 | `输入` + 时间 | 时间/类型/命令/附件；`输入` / `回答` / `工具` / `用量` |
| 工具调用 | 工具摘要 | `成功`/`失败` + 耗时 | 时间/结果/耗时/摘要；`参数` / `结果` |
| MCP 服务器 | 服务器名 | `MCP`/`本地` + 调用数 | 调用列表：时间 + 成功/失败 + 工具 + 耗时 |
| diff 文件 | 文件路径 | `变更` / `整个文件` 切换 + `+N -N` | Code 正文 |
| 文件预览 | 文件路径 | — | Code 正文 |
| 全文 | 输入全文 / 回答全文 | — | 正文 |

- 输入上限 6 行；回答上限半屏（`max(3, floor(bodyRows / 2))`）。
- 不超就不折；「查看全部」进入安静全屏页；`b` 的层级：全屏 → 详情 → 列表。
- 工具/用量不折叠。

### 4.11 BackBar / ScrollHint

- 全局唯一返回：`← 返回`，`hotkey="b"`，`plain`/默认 Button 均可；浮在视口右上角，右距 3。
- `DetailChrome` MUST 是页面根节点**最后一个子元素**，否则被正文覆盖。
- 安静页 `top = scroll.offset`；方向 D 的所有详情页都是安静页，所以不再有 `max(offset, 2)` 的页签偏移。
- 滚动提示：内容超过视口时显示；`N = min(offset + 1, M)`；右距 3；不超屏不显示。

### 4.12 AbovePrompt 横条

**结构**：

```
[ 面板 ] OpenSpec 235/239 ◉1 !2  | MCP 3 | 对话 6  | CTX 62%
```

| 部分 | 规则 |
|---|---|
| 入口 | `[ 面板 ]` 按钮；点击打开面板并聚焦 |
| OpenSpec | `done/total`；进行中 `◉N`、异常 `!N` |
| 计数 | `\| MCP n \| 对话 n`，muted；宽度不足时先丢 MCP、再丢 对话 |
| CTX | `\| CTX n%`；70% 起 `warning`、90% 起 `error`；**宽度不足时最后才丢**；纯文本、不可点 |
| 预算 | 以 `bodyColumns - 9`（`[ 面板 ]` 与一个空格）为可用宽度；任何宽度不溢出 |
| 空读数 | 引擎尚未给出 token 时写 `CTX —`，不写 `0%` |

**反例**：❌ CTX 做成按钮 ❌ 与 MCP / 对话同优先级 ❌ 读数缺失时写 0% ❌ 窄屏把 OpenSpec 挤掉

## 5. 颜色与字重

### 5.1 字重（终端只有两档）

| 档位 | `weight` | 用于 |
|---|---|---|
| 重 | `bold` | 页签选中、详情标题、选中行名称、状态轨道当前项 |
| 常规 | 缺省 | 其余全部 |

- 层级靠颜色与缩进，不靠字重。
- 禁止在 `dimColor` 上再叠加 `weight`。

### 5.2 主题色

| 用途 | ThemeKey |
|---|---|
| 当前/选中/输入 | `claude` |
| 待处理/提问 | `warning` |
| 异常/失败 | `error` |
| 完成/开 | `success` |
| 无单/续轮/结构文字 | `subtle` |
| 规则线/分支竖线 | `inactive` |
| 正文 | 缺省 |

**规则**：
- **颜色只落在状态标签列与状态轨道**；行内其他文字保持灰阶。
- 一屏允许 5 个状态标签色，因为它们共享一列、一个语义；不允许整行上色、不允许背景块。
- 选中行只加 `▸` 与 bold，不改背景、不改标签色。
- 干净工作区的分支轨道没有任何彩色。
- 禁止 hex；禁止 `backgroundColor`（方向 D 不用背景块）。

### 5.3 结构 vs 状态

| 类别 | 上色？ | 例子 |
|---|---|---|
| 结构 | 只许灰阶 | 规则线、分支 `|`、名称、页脚、字段标签、正文 |
| 状态 | 允许主题色 | 状态标签、筛选轨道标签、脏分支计数、开关标签、异常/成功标签、会话统计轨道的 `CTX` 读数、AbovePrompt 的 `CTX` 读数 |

## 7. 窄屏规则（80 / 64 / 56 / 48 / 40 / 24）

| 宽度 | 页签 | 状态轨道 | 次要筛选 | 标签 | 列 | 页脚 | 分支 | 详情 |
|---|---|---|---|---|---|---|---|---|
| ≥80 | 全称 | 全量 | 全称 | 2 字 | done/age/repo/name | `1–5 页签 · 点状态筛选` | 3 行 | 标签 8，返回右 |
| 64–79 | 全称 | 全量 | 全称 | 2 字 | done/age/repo/name | 同上 | 3 行 | 标签 8 |
| 56–63 | 全称 | 全量 | 全称 | 2 字 | done/age/name（无 repo） | 同上 | 名称 14/分支压缩 | 标签 8 |
| 48–55 | 全称 | 紧凑 | 压缩 | 2 字 | done/name（无 age/repo） | `1–5` | 名称 9 | 标签 6 |
| 40–47 | 全称 | 紧凑 | 压缩 | 1 字 | done/name | `1–5` | 名称 9，预览可省 | 标签 6，返回可 `←返回` |
| 24–39 | 短标签/点击 | 只留 全部/进行/异常 | 隐藏 | 1 字 | done/name | `N/M` | 最多 1 行 + 还有 N | 标签 6，返回 `←返回` |

**规则**：
- 任何宽度下都不得横向溢出；不得把一行挤到换行。
- 窄屏丢列的顺序：`repo → age → 次要筛选 → 状态轨道低优先级 → 分支预览按钮`。
- prompt 收藏：<56 列丢弃 `×N`，保留文本与删除。
- 统计轨道与 AbovePrompt 的收缩顺序：会话行**先丢 `CTX`**，仍放不下再把 `缓存读 / 缓存写` 缩写为 `读 / 写`；横条**先丢 MCP、再丢 对话，`CTX` 最后丢**。
- 40–55 列未选中页签为 `plain`（无括号/热键）；<40 列页签只显示短名（`Spec` / `对话` / `MCP` / `音` / `其他`），只保留点击。56 列起恢复括号与 `1–5` 热键。
- 详情标题在 24 列下仍折行，不截断；返回按钮不得压住标题。

## 8. 交互

| 操作 | 行为 |
|---|---|
| 点行 | 进入安静详情页；`index` 指向该行 |

## 10. 反例清单

以下写法一律视为缺陷：

| # | 反例 | 原因 |
|---|---|---|
| 1 | 页面自绘卡片/圆角/左右竖线 | 宽度与截断逻辑各写一遍，必然错位；方向 D 不允许 |
| 2 | 整行取状态色 | 颜色泛滥，扫读先被底色分走；状态应是标签列 |
| 3 | 用 `* o ! + .` 代替状态标签 | 需要先学符号；方向 D 用文字标签 |
| 4 | 状态标签放进行尾 | 第一列才是扫读位；标签必须在行首固定列 |
| 5 | 每个状态一个分组标题 | 5 个标题吃掉 5+ 行；用一行状态轨道 |
| 6 | 状态轨道换行 / 每个状态一行 | 高度爆炸；轨道必须一行 |
| 7 | 选中行加背景色 | 方向 D 只允许 `▸` + bold；背景块留给别的方向 |
| 8 | 用 emoji / `◉` / `▏` / 圆角 Box Drawing | 宽度不稳；方向 D 已移除 |
| 9 | 多个 Fill 列 | 互相挤压，宽度不可预测 |
| 10 | 用 `padEnd` 补中文 | 中文占 2 格，列会错位 |
| 11 | 详情页保留页签 / 状态轨道 / 分支 | 阅读页需要全部宽度；门在右上角 |
| 12 | 详情标题 `endClip` / `truncate-end` | 详情存在的理由就是看全 |
| 13 | 详情值 `truncate-end` | 长路径/文件名被切断，详情失去意义 |
| 14 | 字段标签带 emoji | 宽度失控；方向 D 字段标签纯文本 |
| 15 | 页脚只显示总数 | 用户不知还有多少没看到 |
| 16 | 详情页无返回 | 键盘无法退出 |
| 17 | `plain` + `hotkey` | 渲染出 `1: label` 前缀 |
| 18 | `plain` Button 里放 `<Box>` / fragment | 整页绘制失败 |
| 19 | 分支做回卡片 | 方向 D 去掉卡片；分支是页脚轨道 |
| 20 | 干净分支上绿色 | 绿色泛滥，「干净」失去意义 |
| 21 | 加固定行却不减 `room` | 底部页脚/分支被挤出屏幕 |
| 22 | 折行宽度没扣行首占位 | 行比页面长几格 → 引擎再折一次、断在任意处 |
| 23 | 用 `marginTop` 做间距 | Pane 内不生效 |
| 24 | 硬编码 hex 颜色 | 不跟随用户主题 |

## 12. 与方向 D 的关系

- 本规范取代旧版「圆角卡片 + emoji 标签 + 分组标题 + `z` 折叠」的中心。
- 保留的旧规则：引擎硬约束、`cellsOf` 宽度体系、单一 Fill 列、详情值折行、返回固定、滚动提示、分支末 7 位、扫描与刷新周期。
- 删除的旧规则：卡片上下边、左右留白作为卡片内宽、emoji 白名单、分区标记 `* o ! + .`、分组折叠、`◉` 页签、详情字段 emoji。
- 视觉参考：`design/visual-reset.html` 的方向 D；实现以本文为准，HTML 只是预览，不是网页皮肤。
