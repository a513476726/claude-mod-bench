# bench UI 规范

> Claude Code 开发者面板的界面设计标准。所有界面改动以此为准，不符合的实现视为缺陷。
>
> **分层原则**：本文分「引擎约束」（不可协商，违反即加载失败或错位）与「项目决策」（我们的选择，可迭代，改动需更新本文）。两者不混写。

---

## 0. 设计原则

1. **一列一义**：每个字段占固定列，各列独立截断，永不跨列侵占。所有行左缘对齐成一条线。
2. **字形恒定**：行首槽位宽度固定，符号宽度确定。不因内容变化而移位。
3. **颜色只标状态，不标装饰**：一屏最多 3 种彩色。结构性元素（框线、分隔）一律灰阶。
4. **区域有形状**：页面被切成整宽圆角卡片，标题嵌在上边线。框线是灰阶，内容在框内。
5. **构件优先**：边框、留白、列宽、颜色只能来自 `hooks/ui.tsx` 的构件，页面不得自绘。

**定位**：表格式对齐的信息流 —— 一行一件事，固定列，`git log --oneline` 的密度 + 表格的扫读性，装进几张有边界的卡片。

## 1. 引擎约束（不可协商）

以下来自 `claude-code.d.ts` 与本机实测，**违反会直接出问题**，不是风格偏好。

### 1.1 字符宽度

| 约束 | 说明 |
|---|---|
| **禁用 East Asian Ambiguous 字符** | `●` `○` `★` `⚠` `▶` `▼` 在 CJK 终端可能占 2 格。UAX #11 原文：「不打算给现代终端在未做适配的情况下直接使用」 |
| **emoji 只在标签位** | emoji 宽度实测不一致（kitty/tmux 各有例外）。只允许出现在**页签名、分区名、按钮文案、字段标签、空态首行**这类「标签位」，且 emoji 后**紧跟一个空格**；下一行的内容从同一列起，不依赖 emoji 宽度 |
| **禁用 Nerd Font 图标** | 用户未装字体即成豆腐块，且无法探测 |
| **安全符号集** | 见 §5，全部单格宽度 |
| **中文占 2 格** | 任何补空格、算宽度都必须按显示宽度而非字符数 |
| **Box Drawing 仅限卡片上下边** | `╭ ╮ ╰ ╯ ─` 属 EAW Ambiguous，但在 Claude Code 自己画的 Pane 边框里是单宽；**只允许**出现在卡片上下边，不得进入数据列；卡片不画左右竖线 `│` |

### 1.2 组件能力边界

| 组件 | 能做 | 不能做 |
|---|---|---|
| `Button`（默认） | 带 `[ label ]` 边框、`variant="primary"` 强调、`hotkey` | 自定义颜色 |
| `Button`（`plain`） | 无边框、children 任意树、children 内 `Text` 可上色 | `hotkey` 会渲染成 `1: label` 前缀 |
| `Text` | `color` / `backgroundColor` / `weight` / `dimColor` / `wrap` / `tabular` | — |
| `Box` | `flexDirection` / `flexGrow` / `padding` / `borderStyle` / `gap` | **`marginTop` 在 Pane 内不生效** |

**结论**：
- `plain` Button 的 children **只能是字符串与 `Text`**：放 `<Box>` 或 fragment 会让整页绘制失败（`holds strings and Text, not <Box>`）
- 列表行、分区标题**必须用 `plain`**，否则被 `[ ]` 撑成按钮外观
- `plain` 的 `label` 只是无障碍名，**实际绘制看 children**
- 需要键盘热键的位置（页签）用**默认 Button**，接受 `[ ]` 边框——它反而是页签的视觉语言

### 1.3 布局

| 约束 | 说明 |
|---|---|
| 主动打开的面板需 **≥144 列**才停靠 | 窄屏下挂起不绘制（`isPlaced: false`） |
| 主屏模式（tmux / `NO_FLICKER=0`）**不 dock 面板** | 宽度再大也无用 |
| 列宽优先级（Ratatui 标准） | `Min > Max > Length > Percentage > Ratio > Fill` |
| **只留一个 Fill 列** | 多个弹性列会互相挤压，且 `Length`+`Percentage` 混合时 Percentage 列会被挤到 0 且不显示省略号 |

## 2. 间距体系

间距只有三个值，全部来自 `hooks/ui.tsx` 的 `SP`。**页面不得写字面量空格**。

| 令牌 | 值 | 用于 |
|---|---|---|
| `SP.inline` | 2 | 卡片内左右留白；卡片之间的空行 |
| `SP.group` | 2 | 同一行内两列之间 |
| `SP.section` | 1 | 区域之间（空行行数） |

**禁止**：任意字面量间距、`marginTop`（Pane 内无效）、按 `padding` 猜测宽度。分区间距一律用空 `<Text> </Text>`。

## 3. 布局结构

### 3.1 区域 = 卡片

```
页签栏（卡片外）                        1 行
空行                                    1 行
╭─ 📋 OpenSpec ─────────────── · 4/4 项 ╮   主卡上边线
  <分区 / 筛选 / 表头 / 行 / 页脚>          N 行（左右各留 1 格，无竖线）
╰───────────────────────────────────────╯   主卡下边线
空行                                    1 行
╭─ 🔀 分支 ─────────────────── · 2 个仓库 ╮   分支卡
  * <仓库>   <分支>
╰───────────────────────────────────────╯
```

| 规则 | 说明 |
|---|---|
| 同宽 | 所有卡片宽度 = `bodyColumns`，不缺角、不收缩 |
| 框线 | `inactive` 灰阶；焦点/选中**不改变框线** |
| **只画上下边，不画左右竖线** | 竖线由每一行自己画，行里有 `Button`、多个 `Text` 时宽度不受控，竖线必然错位。圆角上下边已经足够划清区域 |
| 标题 | 嵌在上边线：`╭─ <图标> <区名> ───── · <右侧摘要> ╮`，右侧摘要 `subtle` |
| 边距 | 卡片之间恒 1 行空行；卡内左右各 `SP.inline` |
| 子视图 | 详情 / 下钻 / diff 是**同一张主卡**，层级标题即卡片标题 |
| 安静页 | 全屏正文阅读页没有页签与分支卡，只有卡与右上角返回 |

### 3.2 高度预算

```
列表可见行 = bodyRows − 页签 1 − 空行 2 − 分支卡(2 + 仓库行) − 主卡边 2 − 卡内固定行
```

分支卡仓库行上限 5，超出以「… 还有 N 个仓库」收尾。加任何固定行都要同步扣减列表行数。

### 3.3 水平列定义

列定义只有一处（`panes.tsx` 的 `LIST_COLS`），**表头与数据行都由它生成**，列宽随宽度计算，只有一个 `Fill` 列且位于最末。

- **所有列一律左对齐**：右对齐的数字落在左对齐的表头下面，正是「标题和内容错位」的来源。
- 光标列 `▸` 与状态列 `!` `*` 各占 1 格，排在进度列之前。

```
<cur:2><统一：行首标记><done:7><age:4><repo:14><name:Fill>
```

## 4. 组件规范

每个组件给：**结构模板 / 变体 / 尺寸 / 颜色 / 反例**。前七个是**共用构件**（`hooks/ui.tsx`），页面只能组合它们，不得自己画。

### 4.0 共用构件

| 构件 | 职责 | 约束 |
|---|---|---|
| `SP` / `INK` / `ICON` | 间距 / 灰阶 / 区域图标 | 唯一来源 |
| `topEdge` / `bottomEdge` / `cardRow` | 卡片上边线 / 下边线 / 卡内一行 | 输出宽度恒等于 `columns` |
| `Card` / `CardLine` | 区域卡 / 卡内纯文本行 | 页面的唯一绘制外壳 |
| `CardRule` | 卡内「横线 + 表头 + 横线」 | 只给列表页用 |
| `lineOf` / `widthsOf` | 列定义渲染 | 单 `Fill` 列，最后 |
| `headOf` / `ruleOf` / `footerOf` | 卡内小标题 / 整宽线 / 两端对齐页脚 | — |
| `BackBar`（`backBar`） | 右上角返回 | 文案 `← 返回`，`b` |

### 4.0b Region / Card 区域卡

**结构**：`╭─ <图标> <区名> ───── · <摘要> ╮` / 内容 × N（无竖线）/ `╰─────╯`。

规则：
- 宽度恒为面板列数；标题与右摘要放不下时，**先丢右摘要，再截标题**；
- 框线 `inactive`，不随焦点变化；
- 卡内固定顺序：小标题 → 内容 → 横线 → 表头 → 横线 → 行 → 页脚。

**反例**：❌ 页面自己拼 `─── 标题` ❌ 卡片宽度随内容变化 ❌ 卡内画左右竖线 `│`

### 4.1 TabBar 页签栏

**用途**：切换顶层功能域。

**结构**：
```
◉ [📋 OpenSpec]  [💬 对话]  [🔌 MCP]  [🔊 提示音]
  ↑ 选中：强调色+加粗+实心圈      ↑ 未选中：dimColor
```

| 状态 | 实现 | 外观 |
|---|---|---|
| 选中 | `plain` `Button` + children `<Text color="claude" bold>◉ [名称]</Text>` | 蓝字加粗 + 实心点 |
| 未选中 | 默认 `Button` + `dimColor` | 灰色 `[ 名称 ]` |

**规则**（已实测定稿）：
- 选中态用**前景色变色 + 加粗 + `◉` 前置点**，**不用背景色**（背景块比列表还重）
- 选中态显示 `◉ [名称]`，**不显示热键编号**（`plain`+`hotkey` 会自动画 `1:` 前缀，读起来和名称连在一起）
- 未选中显示 `[ 名称 ]`，热键仍然生效（按 `1`-`4` 可切换）
- 点号用 **`◉` U+25C9（EAW=Neutral）**，不用 `●`（Ambiguous）或 `·`（Ambiguous）
- 页签数量 ≤ 6

**反例**：❌ 用 `backgroundColor` 做选中（视觉过重）❌ 选中态显示 `1:`（与名称粘连）❌ 用 `·`（读起来像 `·1`）

### 4.2 SectionBar 分区标题栏

**用途**：一个页面内的分组，**所有分区标题并列在一行**。

**结构**：
```
▾ * 进行中 7   ▸ o 待归档 5   ▸ ! 归档异常 7   ▸ + 已归档 12   ▸ . 无清单 4
（不加 emoji：分区标记与名称已足够）
```

| 部分 | 符号 | 颜色 | 宽 |
|---|---|---|---|
| 展开/折叠 | `▾` / `▸` | `inactive` | 1 |
| 状态标记 | `*` `o` `!` `+` `.` | 见 §5.2 | 1 |
| 名称 | 文字 | 灰阶（异常除外） | 固定 |
| 计数 | 数字 | 异常=`error`，其他=`subtle` | — |
| 组间 | — | — | 3 空格 |

**规则**：
- **必须并列成一行**，不允许多行——5 个分区各占一行会吃掉 10+ 行
- 超过宽度时**从右侧丢弃**低优先级分区（优先级按 `GROUP_ORDER`）
- 折叠时整组只剩标题，展开时标题下方接行列表
- 整个标题是 `plain` Button，点击切换展开

**反例**：❌ 每个分区占一行 ❌ 分区之间加空行（行数翻倍）

---

### 4.3 List / Row 列表行

**整行取所属分区的颜色**：一条记录属于哪个分区，整行就用那个分区的 `toneOf` 颜色（进行中 `claude`、待归档 `warning`、归档异常 `error`、已归档 `success`、无清单 `subtle`）。行内的状态符号 `* o ! + .` 与分区标题上的是同一套配色。

**反例**：❌ 行内各列自选颜色（同一行三种色，看不出它属于哪个分区）

**用途**：承载一条记录。

**结构**：
```
<光标:2><状态:1><空格><列1><gap><列2><gap>...<列N:Fill>
▸ !     13/16     6d    old_sales        fix-signmanager-full-down-payment
```

| 槽位 | 内容 | 规则 |
|---|---|---|
| 光标 | `> ` 或 `  ` | 仅当前选中行显示 `>`，颜色 `claude` |
| 状态 | `!` / `*` / 空格 | 异常 `error`、最新 `warning`、其余 `subtle` |
| 内容列 | 见 §3.2 | 各列固定宽，`Fill` 列最后 |

**变体**：
| 变体 | 特征 |
|---|---|
| 普通行 | 前景 `text` |
| 警示行 | 状态槽 `!`，颜色 `error` |
| 最新行 | 状态槽 `*`，颜色 `warning` |
| 弱化行 | `dimColor`（已归档、无清单） |

**规则**：
- **必须 `plain`**，不给 `hotkey`（`plain`+hotkey 会出现 `1:` 前缀）
- 整行可点击，点击进入详情
- 长度超出时**最后一列尾截断**，其他列各自独立截断

**反例**：❌ 用 `[ ]` 包住行（变成按钮，混淆层级）❌ 列宽随内容浮动（无法纵向扫读）

### 4.4 Footer 页脚

**结构**：
```
11/35 项 · 点行看详情          [ 展开全部 ]
```

| 部分 | 内容 | 颜色 |
|---|---|---|
| 左 | `<可见数>/<总数> 项 · <操作提示>` | `subtle` |
| 右 | 操作按钮（默认 Button） | — |

**规则**：
- 提示文案 ≤ 20 字，只写「怎么用」，不写「是什么」
- 显示数为 `可见/总数`，**不能只显示总数**——用户需要知道还有多少没看到
- 右侧按钮最多 1 个

**反例**：❌ `11/11 项 · 共 35 · 点分区标题收起 · 点一行看详情`（冗余，且 `11/11` 让人以为看全了）

### 4.5 BranchBar 分支栏

**用途**：显示工作区各仓库的当前分支。

**结构**：
```
-- 分支 -------------------------
* 根目录        master
| old_sales     develop_20_20261021084
| sales-plat…   develop_20_20261012001
```

| 部分 | 规则 |
|---|---|
| 分隔线 | `--` + 填充 `-` 到面板宽度，`inactive` |
| 根目录标记 | `*`，`suggestion` 色 |
| 子仓库标记 | `|`，`inactive` 色 |
| 名称列 | 固定 15 格，超出中截断 |
| 分支列 | 剩余宽度，**保留首尾**（前缀 + `…` + 末 7 位） |

**为什么保留末 7 位**：`develop_20_20261012001` 与 `develop_20_20261021084` 前 20 位相同，只截尾无法区分。尾部才是需求号的区分点。

**规则**：一仓一行，**绝不横排**（横排 80 列必挤成一团）。

**仓库发现**：
- 会话目录自身是仓库（有 `.git` 或 `openspec/`）→ 第一行，名称列显示目录名。
- 工作区取会话目录上一级起**向上最多 2 层**中第一个「装着仓库的目录」。
- 工作区根自身是仓库 → 「根目录」行（`*`）。
- 工作区下每个带 `.git` 或 `openspec/` 的子目录 → 一行，按名称排序。**不使用仓库名白名单**。
- 去重；`node_modules` 跳过。

**行数上限**：最多显示 6 行仓库，超出时末行显示 `… 还有 N 个仓库`。

**刷新**：会话启动、每轮结束、以及面板打开期间每 5 秒一次（`BRANCH_POLL_MS = 5000`，只刷分支不重扫 OpenSpec）。内容签名未变不重绘。

### 4.5b 会话统计区（对话页签）

**用途**：对话列表上方的会话级汇总。

**结构**：
```
─── 会话
  claude-opus-5-5（6 轮） 入 120000 · 出 8000 · 缓存读 340000 · 缓存写 21000
  合计 入 120000 · 出 8000 · 缓存读 340000 · 缓存写 21000
  工具 5 种 · 42 次
  命令 17 次
```

| 部分 | 规则 |
|---|---|
| 标题 | `─── 会话`，`inactive` |
| 模型行 | 每模型一行，按轮数降序；最多 4 行 + 合计 |
| 工具 / 命令 | `plain` Button，`label` 为整行文字（无障碍名），实际绘制看 children |
| 小面板 | `bodyRows < 20` 时模型行只留 1 行 |
| 空态 | 无已结束轮次时模型位显示「（暂无用量）」 |

**行数扣除**：统计区占 `4 + 模型数` 行，从对话列表可见行数中扣除。

### 4.5c 下钻

**规则**：
- 下钻栈存在 `view.path: string[]`，空 = 页签自己的列表。
- 每层一个 `plain` Button，`key` 为 `drill-<下一步 id>`，按压 push 一层。
- 最后一层（单次调用）是只读详情，不产生新层。
- `b` / `← 返回` 弹出一层。
- 切换页签、打开行详情、返回列表时，`path` 一律清空。

### 4.5d 提示音页签

**用途**：控制会话提示音，并提供试听。**面板不绘制宠物。**（2026-11-06 起）

**结构**：
```
─── 🔊 提示音
  🔊 [开]  总开关                        ▶ 试听
  🔊 [开]  需要决策                      ▶ 试听
  🔇 [关]  任务完成                      ▶ 试听
  🔊 [开]  任务异常                      ▶ 试听
```

| 部分 | 规则 |
|---|---|
| 状态 | `🔊 [开]` 绿色 / `🔇 [关]` 弱化色 |
| 切换 | 点整行立即切换，**只写一次**（不在 `ui.press` 里重复处理，否则翻两次等于没翻） |
| 试听 | 行尾 `▶ 试听` 独立按钮，当场播放该行声音；不受该行自身开关限制 |
| 总开关 | 关闭时任何提示音都不播放；总开关行的「试听」播放 `done.wav`，用于确认音频链路 |
| 详情 | 无（本页所有行都是开关，不打开详情） |

### 4.5e 返回按钮与筛选行

**返回按钮（全局唯一）**：所有详情与下钻视图在内容区**右上角**（`position: absolute, top: 0, right: 0`）显示同一个按钮：

```
← 返回
```

| 规则 | 说明 |
|---|---|
| 文案 | 统一「← 返回」，`hotkey="b"` |
| 位置 | 内容区右上角，绝对定位；不随内容滚动 |
| 层级 | 下钻 → 上一层；详情 → 列表；最外层不显示 |
| 标题行 | 同层的标题行右侧为其留出宽度，避免与长标题重叠 |

**筛选行（OpenSpec 页签）**：

```
  筛选 仓库：全部 · 时间：全部        ← 有筛选时末尾多一个「清除」
```

| 部分 | 规则 |
|---|---|
| 仓库 | 在「全部」与扫描到的仓库之间循环 |
| 时间 | 全部 → 今天 → 近 7 天 → 近 30 天 循环 |
| 生效显示 | 非「全部」的项以 `claude` 色显示 |
| 清除 | 任一筛选生效时出现 |

### 4.6 Detail 详情

**卡内分区**：一段内容自成一个小区块，用左缘竖线 `▏`（`inactive`）表明它从哪里开始、到哪里结束；标题带 emoji、贴着这条线，正文再往内缩一层。

```
 ▏ ✍️ 输入
 ▏   你好？
 ▏ 💬 回答
 ▏   如果需要我干活，直接说要做的事就行 —— 比如：
 ▏   - 前端页面开发
 ▏   - 老系统重构核对
 ▏ 🔧 工具
 ▏   （本轮没有调用工具）
 ▏ 🎫 用量
 ▏   ⏱️ 耗时   3.0s
 ▏   🤖 模型   deepseek-flash
```

| 规则 | 说明 |
|---|---|
| 左缘标记 | `▏`，每行都画，区块的上下界一眼可见 |
| 标题 | **一律「emoji + 名称」**，与详情字段标签同一套写法；**不再用 `── 标题`** |
| 缩进 | 卡内缩进 `SP.inline`，正文再缩 `SECTION_INDENT`（4 格） |
| 换行 | 正文**按区块内宽折行**（`wrapCells`，宽度已扣掉缩进），永不 `truncate-end` |
| 折叠说明 / 「查看全部」 | 同样贴着左缘线、缩进到正文列 |
| 空行 | 源文本里的空行不画成裸 `▏` 行 |

**分区图标**：输入 `✍️` · 回答 `💬` · 工具 `🔧` · 用量 `🎫` · 参数 `🔧` · 结果 `📋`


详情是**一张独立的卡**：变更名（或轮次摘要）作卡片标题，标题前带区域 emoji；字段两列，标签带 emoji。

```
╭─ 📋 fix-signmanager-full-down-payment-20260920 ───────────────╮
📁 仓库    sales-platform
📌 状态    待归档
✅ 任务    10/10
🔢 需求号  （proposal.md 未写）
👤 开发    zhongzhiguo
📄 文件    tasks.md, proposal.md, specs/change-spec.md,
           specs/design.md
✏️ 修改    11-02 14:32（1d 前）
╰────────────────────────────────────────────────────────────────╯
```

| 部分 | 规则 |
|---|---|
| 卡片标题 | 条目名；`╭` 后先留 **1 格内缩**再放区域 emoji（`╭─  📋 名称`），与卡内行的内缩对齐 |
| 标签列 | 10 格，`subtle`，**左缘对齐**：卡内缩 1 格后即标签列，所有字段（带不带 emoji）的值都从同一列起 |
| 值列 | 剩余宽度，正文色；**超长自动换行**（插件按显示宽度自行折行），**不得截断** |
| 续行 | 换行后的续行标签列留空；**值的最后一行**末尾以 `subtle` 注明「（共 N 行）」 |
| 裸文本行 | 任务原文等不带 `:` 的行：`1. ` 序号留在首行，续行缩进到正文列并以 `inactive` 的 `│` 起头 |
| 字段图标 | 时间 `🕒` 仓库 `📁` 状态 `📌` 任务 `✅` 需求号 `🔢` 开发 `👤` 文件 `📄` 修改 `✏️` 类型 `🏷️` 命令 `⌨️` 附件 `📎` 归档于 `📦` 耗时 `⏱️` 用量 `🎫` 模型 `🤖` 结束 `🔚` 结果 `📋` 摘要 `📝` |
| 返回按钮 | 卡片右上角，`← 返回`，`hotkey="b"` |

**为什么值要换行**：详情页存在的理由就是看全一个长路径、一串文件名、一条任务的原文。在卡片边缘切断，等于把人打开详情想看的东西藏起来。

**为什么由插件自己折行**：Pane 的行宽由这个模块自己排版，`Box flexGrow` 在 Pane 里能否撑满没有保证；让引擎排版一旦判断不同，值会整段消失。`wrapCells(line, room)` 按 `cellsOf`（含 emoji 宽度）折行。

**折行宽度必须扣掉行首占位**：值列要减去 `SP.inline` 与标签列宽，裸文本行要减去内缩、`│` 位与 `1. ` 序号。少扣 2–3 格，行就比卡片长几格，**引擎会把它再折一次**——在任意位置断开，这正是「211/229 │ 测试库…」那种错位的来源。

**返回按钮**：`Card` 把返回按钮放在**卡片上边线那一行**里（该行是 `position: relative` 的父级），按钮 `position: absolute; top: 0; right: SP.inline+1`，**浮在卡片右上角**。不要把它挂在一个包住整张卡的外层 `Box` 上——外层高度等于正文高度，长文件时按钮会随内容滚出可视区。有返回时标题右侧预留约 10 格。

**详情是独立页面**：详情 / 下钻 / 文件 / 全屏正文只有「页签 + 一张卡」，**不显示分支卡**——打开详情是为了读一件事，分支卡会挤掉正文空间。列表页才显示分支卡。

**反例**：❌ 值用 `wrap="truncate-end"` ❌ 字段标签不带图标（用户要求：标题前尽量用 emoji）❌ 标题行与数据行来自两套列宽

## 5. 文字与颜色规范

### 5.1 字重体系（终端实际两档，已实测）

> **重要**：设计上的四档在终端**做不到**。引擎原文：「The terminal draws `semibold` and `bold` as bold」——`semibold` 与 `bold` 渲染完全相同，`medium` 与 `regular` 也分不出来。

**实际可用只有两档**：

| 档位 | `weight` | 用于 |
|---|---|---|
| **重** | `bold` | 页签选中、详情页标签 |
| **常规** | 缺省 | 其余全部 |

**层级不靠字重，靠颜色**（实测结论：用户反馈「加粗不明显」）。分区标题的层级用 `toneOf()` 的颜色表达，不用 `weight`。

**禁止**：在 `dimColor` 上再叠加 `weight`（渲染不可预测）。

### 5.2 颜色映射（主题色 + 5 色分区，已定稿）

**主题色（Accent）＝ `claude`** —— Claude Code 品牌色，含义「当前/活跃」。**所有选中态一律用它**：

| 位置 | 用法 |
|---|---|
| 页签选中 | `color="claude"` + `bold` |
| 分区「进行中」 | `toneOf` → `claude` |
| 列表行光标 `▸` | `color="claude"` |
| 筛选生效项、可下钻的小标题 | `color="claude"` |
| 横条进行中计数 | `color="claude"` |

跟随用户主题自动变色，不硬编码。

**分区色板（5 色）**：

| 分区 | ThemeKey | 含义 |
|---|---|---|
| 进行中 | `claude` | 当前在干 |
| 待归档 | `warning` | 等着处理 |
| 归档异常 | `error` | 出问题 |
| 已归档 | `success` | 已闭环 |
| 无任务清单 | `subtle` | 信息量最低 |

**灰阶**（`INK`）：正文 `body`（缺省）/ 次要文字 `muted`（`subtle`）/ 框线与分隔 `frame`（`inactive`）/ 已完成内容 `dimColor` / 反色前景 `inverseText`

**结构 vs 状态**：

| 类别 | 上色？ | 例子 |
|---|---|---|
| 结构 | 只许灰阶 | 卡片框线、分隔线、表头、详情字段标签、**分支名** |
| 状态 | 允许主题色 | 分区标记与名称、行光标、失败/最新标记、脏工作区计数、提示音开关 |

**规则**：同一语义全项目同色；一屏同时出现的彩色语义 ≤ 3 种；干净工作区的分支卡**没有任何彩色**；禁止 hex。

## 6. 字符集（安全符号）

| `╭ ╮ ╰ ╯ ─` | 卡片上下边 | 仅卡片上下边（不画 `│`） |

| `o` | 待处理 | 状态槽、分区标记 |

## 10. 对话页（conversation）

**列表行**：`<光标:2><标记:1><时间:5><空格:1><首行摘要:Fill>`

```
▸ ·06:13 把分支状态改成一仓一行
  ◆08:40 按轮次还是按消息逐条？
  !↻09:02 （续轮）
```

| 槽位 | 取值 | 颜色 |
|---|---|---|
| 标记 | `·` 你输入 · `◆` AI 提问 · `↻` 续轮 · `!` 有失败或未正常结束 | 失败 `error`，其余 `subtle` |
| 摘要 | 输入的第一行，尾截断 | `text` |

失败判定：结束原因为中断 / 拒绝 / 报错，或本轮有工具调用失败。失败时标记槽画 `!`，原标记信息在详情里仍有。

**详情**（自上而下）：

```
时间: 11-04 09:02
类型: 输入
命令: /opsx:apply          （有 slash 命令时）
附件: 1 个                （有附件时）
── 输入
（最多 6 行）
…（共 30 行，已显示 6 行）
[ 查看全部输入 ]
── 回答
（最多半屏：floor(bodyRows / 2) 行，最少 3 行）
…（共 200 行，已显示 20 行）
[ 查看全部回答 ]
── 工具
Read ×2 · Bash ×1（失败 1）
── 用量
耗时: 1.2s
用量: 入 1200 · 出 340 · 缓存读 8000 · 缓存写 2100
模型: claude-sonnet-5-5
结束: 回答
```

**折叠规则**：
- 输入上限 **6 行**；回答上限 **半屏**（`max(3, floor(bodyRows / 2))` 行）。
- **不超就不折**：内容没到上限时原样全展，不出现说明行和按钮。
- 行数按显示宽度估算（`cellsOf` 折行），随面板宽度重算；`items.ts` 不截断，截断只发生在绘制层。
- 「工具 / 用量 / 结束」**不折叠**，始终在折叠后的同一屏内。
- 点了「查看全部」进入全屏视图：标题 `── 回答（共 N 行）`、正文全文、底栏 `[ ← 返回详情 ]`（`b` 同效）。`b` 的层级是：全屏视图 → 详情 → 列表。
- 引擎未给的字段显示 `—`，不显示 0。进行中的一轮结束原因为「进行中」。

**空态**：`本会话还没有对话。你提交输入、或 AI 发起提问后，这里会出现一轮记录。`
