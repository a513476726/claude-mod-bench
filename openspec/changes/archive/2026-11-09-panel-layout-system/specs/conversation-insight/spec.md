# Spec Delta

## MODIFIED Requirements

### Requirement: 所有层级的返回是同一个按钮

面板 SHALL 在所有详情与下钻视图里提供同一个返回入口：**定位在卡片右上角**，文案与行为一致，`b` 键等价于按下它。

返回的层级 SHALL 固定：

- 下钻层级 → 上一层；
- 列表的详情 → 该列表；
- 最外层（页签自己的列表）不显示返回。

#### Scenario: 轮次详情返回列表

- **WHEN** 打开一轮的详情，按下右上角返回（或按 `b`）
- **THEN** 回到对话列表，选中行不变

#### Scenario: 下钻逐层退回

- **WHEN** 处在「某次调用」这一层，连续按返回
- **THEN** 依次回到该工具的调用列表、工具分组、对话列表
- **AND** 到最外层时不再显示返回按钮

#### Scenario: 各处返回一致

- **WHEN** 分别打开 OpenSpec 变更详情、分支 diff 文件列表、diff 单文件、对话轮次详情
- **THEN** 四处都显示同一个右上角返回按钮，位置与文案一致
