# Proposal

## Why

面板已经能读到全部信息，但**看起来像若干段各自为政的裸文本**：区域之间只靠一行 `─── 🖥 功能` 区分，列表列没有任何边界，分支区是一条 `* 根目录 main`，详情页几种排法混在一起。用户的实际反馈是「布局和区域划分不清晰、不规则、边界不明确」「配色混乱」「一个页面一个规范」。

根因是三条规范没有落成**可复用的构件**：

1. **区域没有形状**：页签、分区栏、筛选、表头、列表、页脚、分支区各自手绘，没有统一的「区域」容器。于是每个页面对边界、留白、标题的处理各不相同。
2. **图标失控**：页签、分区、表头、详情字段、分支区都塞了 emoji（`📋 💬 🔌 🔊 ⚙️ ⏳ ⚠️ ✅ 📄 🕒 📁 📌 🔢 👤 📝 🔧 ⌨ 🎫 🤖 …`）。它们宽度不一、不受主题色控制、在每个页面上位置不同——这正是「花、乱」的主要来源。
3. **一处一个颜色**：分区名按状态着色、表头无颜色、详情标签灰、分支 `success` 绿，没有统一的「结构灰 / 状态彩」分工，一屏彩色元素常常超过 3 种。

不改的后果：每加一个页面或区域，都要重新决定一遍边框、留白、颜色，面板的混乱会随功能线性增长。

## What Changes

**视觉语言：框线卡片 + 单色强调。**

- **区域卡片（Region）**：页面被切成若干**整宽圆角框**（`borderStyle="round"`），标题嵌在框的上边线里（`╭─ 📋 OpenSpec ─────🔀 根目录  main─╮`）。框线一律 `inactive` 灰阶，彩色只留给状态。区域之间留 1 行空行。
- **页面骨架统一为三块**：
  - **主区域卡**：页签栏（卡片外的顶栏）+ 内容卡（分区栏 / 筛选 / 表头 / 列表 / 页脚都在一张卡里）；
  - **分支卡**：每仓一行，脏仓库仅在行尾给出彩色计数与「预览」。
  - 详情、下钻、diff、全屏正文同样是**一张卡**，标题即卡片标题，返回按钮浮在卡片右上角。
- **共用构件收进 `hooks/ui.tsx`**：`Frame`（页面骨架）、`Card`（区域卡）、`CardHead`（卡内小标题）、`Rule`（卡内整宽分隔）、`Row`/`Cells`（列表行与表头共用同一套列定义）、`Footer`、`BackBar`。所有页面的公共部分**只定义一次**。
- **图标收敛到「区域图标」一张表**：只保留页签与卡片标题的 4 个图标（`📋 💬 🔌 🔊`）和分支卡的 `🔀`。分区标记、表头、详情字段、列表行**移除全部 emoji**，改用已约定的单宽符号 + 主题色。
- **间距 / 颜色落成常量**：`SP`（0/2/4 栅格）、`TONE`（状态→主题色）、`INK`（结构灰阶：`inactive` 框线 / `subtle` 次文字 / 默认正文 / `claude` 强调）。任何绘制只能引用它们。
- **列定义单一来源**：`COL` 表头、数据行、详情共用，列宽由 `columns` 计算而不是写死 80，窄屏下按优先级收缩。

## Capabilities

### New Capabilities

- `panel-layout`: 面板的区域划分、共用构件、间距栅格、配色与图标规范，以及所有页面必须遵守的骨架。

### Modified Capabilities

- `branch-status`: 分支区由裸行改为独立卡片，标题在卡框上，脏仓库计数与「预览」按钮固定在行尾。
- `spec-progress-scan`: OpenSpec 页的分区栏、筛选行、表头、列表、页脚落入同一张内容卡，表头与数据列共享列定义。
- `conversation-log`: 对话页的会话统计、详情、全屏正文改为卡片骨架，详情字段去掉 emoji。
- `conversation-insight`: 下钻层级改为卡片骨架，层级标题作为卡片标题。
- `sound-alerts`: 提示音页改为卡片骨架，开关行与「试听」对齐到同一列。

## Non-goals

- 不改变任何数据来源、扫描规则、触发时机或提示音行为——**纯展示层**变更。
- 不引入除现存 emoji 以外的图形资源；不使用 Nerd Font / Powerline。
- 不做横向滚动、侧栏、悬浮卡；不改变页签数量与语义。
- 不重做 `Code` 组件（diff / 文件正文）本身，只调整它的卡片外壳。

## Impact

- 新增：`hooks/ui.tsx`（共用构件与设计令牌 + 对应测试 `hooks/ui.test.tsx`）。
- 改动：`hooks/panes.tsx`（所有页面改用构件绘制）、`hooks/items.ts`（详情行去掉图标前缀；会话/下钻标题）、`hooks/format.ts`（如需宽度辅助）、`hooks/register.tsx`（窄屏 band 行的分隔与颜色统一）。
- 规范：`docs/UI-SPEC.md` 重写 §2 间距、§3 布局、§4 组件（新增 Region / Card / Rule / Cells）、§5 颜色、§6 图标白名单收缩、§9 检查清单；`docs/SKILL.md` 视觉基线同步。
- 测试：现有断言中依赖 emoji / 分区标签原文的用例需同步；新增 `ui.test.tsx` 覆盖构件的框线、标题、间距与降级。
- 类型：无新增 atom，`types/index.d.ts` 不改。
