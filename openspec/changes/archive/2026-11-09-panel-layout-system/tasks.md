- 去掉卡片左右竖线 `│`，只保留上下圆角边：竖线需逐行自补，行内含 `Button` / 多个 `Text` 时宽度不受控，边界必然错位。

## 复核反馈 · 第二轮（2026-11-06）

- **表头与数据行错位**：根因是两套列宽——表头读 `LIST_COLS`，数据行读另一组常量。改为两者都由 `LIST_COLS` 生成，**全部左对齐**（右对齐的数字落在左对齐表头下正是错位来源）；列结构改为 `cursor/mark/progress/age/repo/name`。
- **详情页独立 + 标题 emoji**：所有详情/下钻/全屏正文都是独立卡片页，卡片标题前带区域 emoji（`📋 💬 🔌 🔊`），文件 `📄`、调用 `🔧`。
- **详情长文本自动换行**：`fieldLine` 改为「标签列 10 格 + 值列填充」的 `Box` 布局，值 `wrap="wrap"`，不再 `truncate-end`；字段标签带图标（`🕒 时间`、`📁 仓库` …），标签文字保留。
- **新增测试**：表头/数据行同表左对齐（`ui.test.tsx`）、详情值换行且不截断（`scan.test.tsx`）。
- 85 条测试全绿，`tsc` 0 错误，validate 与 openspec 校验通过。

## 复核反馈 · 第三轮（2026-11-06，截图）

- **多一个 `╮`**：`cellsOf` 不把 emoji 计为 2 格，卡片边线少算 1 格（实测 100 列卡片画出 101 格），引擎丢掉右边角。已补全 emoji 区段并在边线测试中断言。
- **详情字段值为空**：值列依赖 `Box flexGrow` 撑开，引擎排版时整段消失。改为插件侧 `wrapCells` 按显示宽度折行，不再依赖引擎的 Box 宽度。
- **标题贴左**：`╭─` 后增加 1 格内缩，与卡内行对齐。
- **返回悬浮右上角**：由 `screen()` 统一放置 `position: absolute; top:0; right:SP.inline+1`；有返回时标题右侧预留约 10 格。
- **行数显示 / 高亮**：折行值末行注「（共 N 行）」；裸文本行续行首列画 `│`。
- **详情页独立**：列表行与详情已是两个页面（各自一张卡）。
- 87 条测试全绿，`tsc` 0 错误。

## 复核反馈 · 第四轮（2026-11-06，截图）

- **缩进错位 / 行被二次折断**：`wrapCells` 的可用宽度没扣行首占位（内缩、标签列、`1. ` 序号），行比卡片长 2–3 格，引擎按自己的宽度再折一次。已按实际列位扣减。
- **序号行没有统一缩进**：`1. ` 序号留在首行，续行缩进到正文列并以 `│` 起头。
- **详情应为独立页面**：详情 / 下钻 / 文件 / 全屏正文不再显示分支卡。
- **返回按钮不悬浮 / 长文件看不到**：按钮原来挂在包住整张卡的外层 Box 上（高度=正文高度），改为挂在卡片上边线那一行内，`position: absolute` 相对它定位。
- **文件页没有文件名行**：标题已含文件名与路径，重复的行已删除。
