## 1. 初始理解

要求面板里所有详情页与最内层页面：内容超过一屏时能滚动看完；「← 返回」始终浮在右上角、随时可点；详情页里因「一行展示不开」而被截断的内容，除表格行外全部改为换行展示完整。

把握最低的部分：返回按钮挂在卡片上边线行内（`panes.tsx:205-208`），按引擎文档 Pane 滚动整棵树，理论上会随内容移出；但 `docs/UI-SPEC.md` 与归档设计声称它「不随内容滚动」。这一点必须在真机上验证。

## 3. 事实自取记录

| 事实 | 来源（文件 / 表 / 命令） | 结论 |
| --- | --- | --- |
| `panes.tsx` 没有任何 `height` 限高 | `grep -n "height=" hooks/panes.tsx` | 正文不被裁切，超屏即由引擎滚动 |
| 返回按钮统一由 `backBar()` 生成，绝对定位 `top:0; right:SP.inline+1`，挂在卡片上边线行内 | `hooks/panes.tsx:926-936`、`:205-208` | 滚动后随上边线行移出窗口 |
| Pane 滚动是整棵树的窗口，`scroll.offset` 是窗口第一行，`contentRows - bodyRows` 是最大偏移 | `.claude-plugin/types/claude-code/index.d.ts:12750-12776` | 绝对定位子元素随父级/树移动，不会自动钉住 |
| `position: absolute` 按父级定位，`top` 为相对父级上边的行数 | 同上 `:948-953` | 可用 `top = scroll.offset` 把浮层补偿回视口顶部 |
| `ui.scroll` 的输入含 `contentRows`，且滚动时渲染 hook 会以新 offset 重跑 | 同上 `:15582-15645`、`:12761-12767` | 总行数只能从 `ui.scroll` 事件拿；首屏 props 只有 offset/bodyRows |
| `Code` 默认 `wrap='wrap'`，长行会折行 | 同上 `:1662-1710` | Code 页总行数无法在首屏按源码行数精确计算 |
| 引擎单棵树序列化上限约 100,000 字符、20,000 节点 | 同上 `:1443` | 展示预算必须留余量，不能全量展开大会话/大 MCP 记录 |
| 对话下钻列表按 `rows - 2` 切片 | `hooks/panes.tsx:469` | 未扣页签 1 + 空行 1 + 卡片边 2，仍会溢出 2-3 行 |
| diff 文件列表按 `rows - 3` 切片 | `hooks/panes.tsx:334`、`:404` | 未扣页签与空行，「…还有」行可能落在视口外 |
| 全文页每行 `wrap="truncate-end"` | `hooks/panes.tsx:508` | 全文页长行被直接截断 |
| diff 文件详情头部用 `clipRow` 截 repo/path，整行再 `truncate-end` | `hooks/panes.tsx:374-376` | 完整路径在正文里看不到 |
| 单文件预览标题=文件名、aside=路径 | `hooks/panes.tsx:320`、`hooks/ui.tsx:69-88` | 名称与路径都可能被 `endClip` 截断或整个 aside 被丢弃 |
| OpenSpec 详情标题=变更名，正文从第 2 行开始 | `hooks/panes.tsx:565`、`hooks/items.ts:330-343` | 长变更名只留截断版 |
| 未完成任务只取前 12 条、每条 160 字 | `hooks/items.ts:342-343` | 展示层主动切内容 |
| MCP 服务器详情只取最近 40 次调用、每次 8 行 | `hooks/items.ts:368-374` | 展示层主动切内容 |
| 存储层上限：会话文本 20k、工具参数 2k、结果 400、MCP 参数 20k、结果 4k、文件 60k | `hooks/conversation.ts:16-24`、`hooks/register.tsx:261,275`、`hooks/files.ts:122` | 数据本身可能只到这里，需在截断处说明 |
| 折叠区有「查看全部」入口 | `hooks/panes.tsx:1100-1180` | 折叠是显式操作，不是单行截断 |
| 主列表、diff 文件列表、对话下钻列表、分支卡、提示音行都用固定列宽 + `truncate-end` | `hooks/panes.tsx:412,483,713,813,679` | 表格语义，允许截断 |
| `CardLine` 同时用于表格行与列表页空态 | `hooks/panes.tsx:218-226`、`:627,655,660,662,667,691` | 空态不是表格，需换行；表格行保留截断 |
| `wrapCells` 在行首全为空格时会丢失缩进 | `hooks/panes.tsx:970-1019` | 全文页若用它换行，代码缩进会丢，需要保留前导空白 |
| 现有 specs 声称返回「不随内容滚动」 | `openspec/specs/panel-layout/spec.md:36`、`openspec/specs/branch-status/spec.md:32` | 与实现不符，本次同步修正 |
