# Spec Delta

## MODIFIED Requirements

### Requirement: 文件详情可完整滚动

diff 预览中的文件详情（「变更」与「整个文件」两种读法）SHALL 把正文完整交给面板滚动：正文不被屏幕高度截断，用户可用方向键、`j/k`、PageUp/PageDown、滚轮看完全部内容。

返回按钮 MUST 固定在视口右上角，不随正文滚动移出屏幕；卡片标题与「变更 / 整个文件」切换标签 MAY 随正文滚走。

仓库与文件路径 SHALL 在正文里以可换行字段完整显示，MUST NOT 使用行尾截断。diff 文件列表的仓库名 MUST 出现在正文首段；列表行本身 MAY 按列宽截断。

diff 源文本超过 60,000 字时 SHALL 截断，并在正文写明「…（diff 超过 60,000 字，已截断）」。

#### Scenario: 打开一个很长的文件

- **WHEN** 在 diff 预览中点开一个 200 行的文件
- **THEN** 详情显示文件开头，向下滚动可以一直看到最后一行
- **AND** 返回按钮始终停在视口右上角

#### Scenario: 切换两种读法

- **WHEN** 在「整个文件」里滚到中段，点「变更」
- **THEN** 正文切到 diff，窗口回到顶部
- **AND** 再点「整个文件」同样从顶部开始

#### Scenario: 长路径

- **WHEN** 打开一个路径超过卡片宽度的文件详情
- **THEN** 完整仓库名与文件路径在正文里换行显示
- **AND** 不出现 `…` 结尾的路径

#### Scenario: 滚到文件末尾

- **WHEN** 在「整个文件」里滚到最后一行
- **THEN** 返回按钮仍在视口右上角，点击或按 `b` 回到 diff 文件列表

#### Scenario: diff 列表的仓库名

- **WHEN** 打开某个仓库的 diff 文件列表
- **THEN** 完整仓库名出现在正文首段
- **AND** 文件列表行仍按列宽截断、列对齐

#### Scenario: diff 源文本超长

- **WHEN** 某仓库的 diff 文本超过 60,000 字
- **THEN** 正文写明「…（diff 超过 60,000 字，已截断）」
- **AND** 不显示裸省略号
