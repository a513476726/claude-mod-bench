## 1. 初始理解

顶部页签从 4 个扩到 5 个，新增「其他」；「其他」先显示功能入口，点「prompt 收藏」进入收藏列表：可添加常用 prompt，点一下复制到剪贴板；列表按复制次数降序、同次数按新增时间倒序。

质询前把握最低的：入口层级、存储范围、添加方式、复制后是否立即重排。

## 3. 事实自取记录

| 事实 | 来源（文件 / 命令） | 结论 |
| --- | --- | --- |
| 剪贴板 API 已存在 | `.claude-plugin/types/claude-code/index.d.ts:2629`、`UiCopyResult:14940` | `$.ui.copy({ text, surface })`；成功 `isCopied: true`，失败带 `no-surface / no-clipboard / refused` |
| Button 的 press 带 surface | `index.d.ts:1195-1197`、`UiPressArgument:15479` | `onPress: press => $.ui.copy({ text, surface: press.surface })` 可直接用 |
| 命令名只允许字母、数字、`_`、`-`（≤64） | `CommandSpec` | 冒号不合法；`panel:prompt-add` 被拒，改为 `panel-prompt-add` |
| 命令参数是一整行字符串 | `CommandRunInput.args`（`1814-1850`） | `/panel-prompt-add <文本>` 取 `args` 后 trim；多行不支持 |
| 页签当前 4 个，页脚写死 `1–4` | `hooks/panes.tsx:38`、`978-981`；`docs/UI-SPEC.md §4.1/§7` | 新增第 5 个要改 `TABS`、热键、页脚、窄屏短名、文档与测试 |
| 持久化只有文件 API | `$.fs.write`（`3382`）、`$.env.get("HOME")`（`3751`）；无 `mkdir` | 写 `~/.claude/bench-prompts.json`（父目录已存在，无需建目录） |
| `Input` 仅 terminal/desktop/vscode 有，mobile 没有 | `Elements`（`3963+`） | 本方案用命令添加，刻意不依赖 `Input` |
| 没有插件专用数据目录 | 全仓 grep `dataDir` 无命中 | 路径由本方案自定（全局文件） |
