# Prompt 收藏（其他页签）

> 需求号：不适用（工具项目，无需求号）
> 需求来源：口述记录（2026-11-18 会话）
> 编写者：zhongzhiguo(www.zzginfo.top)
> 状态：草案（grill-me 产出，`/opsx:propose` 时定稿）

## Why

常用 prompt（评审、回归、提交、排查话术）每次都要重新打一遍，或者翻历史记录复制。面板已经在手边，应该有一个地方集中存放并按使用频率排序，点一下就能复制；不打开面板时也能用斜杠命令随时收藏。

## What Changes

1. **第 5 个页签「其他」**：标准列表页，热键 `5`；页内只有一行功能入口「prompt 收藏」（只写名称，不带条数）。
2. **功能页**：点入口进入安静页（无页签、右上 `← 返回`，`b` 等价），列出已收藏的 prompt。
3. **列表行**：显示 prompt 首行 + 行尾 muted 的复制次数 `×N`；点行即复制到剪贴板；不进入详情。
4. **复制反馈**：成功后页脚短暂显示「已复制」（约 2 秒恢复）；失败显示原因且**不**计数。
5. **添加**：斜杠命令 `/panel-prompt-add <单行文本>`；成功后回一句结果，不打开面板；空参数回用法；完全相同（trim 后）文本视为重复，不新增并回「已存在」。
6. **删除**：行尾「删除」→ 页内二次确认「确认删除？」（删除 / 取消）；不提供编辑。
7. **排序**：复制次数降序；次数相同按新增时间倒序。复制后不立即重排；**每次进入列表页**（从入口进入、切回页签、重开面板）按最新数据重排。
8. **存储**：全局文件 `~/.claude/bench-prompts.json`；换项目、重开会话都可见。不设条数与单条长度上限。
9. **空态**：没有收藏时提示「还没有收藏。用 `/panel-prompt-add` 添加。」

## Non-goals

- 不做编辑（要改就删了重加）。
- 不支持通过命令添加多行文本；不做文件导入。
- 不设条数 / 长度上限。
- 不同步、不分享、不跨机器。
- 命令成功后不自动打开面板。
- 不依赖面板内 `Input`（mobile 端没有该元素）。
- 不改 OpenSpec / 对话 / MCP / 提示音页签的行为。

## 兼容性约束

- **状态**：新增 `prompts` 状态（shape `prompts-1`）并同步 `types/index.d.ts`；文件为唯一持久化来源。
- **文件**：`$.fs.read/write` + `$.env.get("HOME")`；父目录 `~/.claude` 已存在，无需建目录；读失败落到空列表并提示，不覆盖损坏文件。
- **引擎命令**：`CommandSpec.name` 只允许字母、数字、`_`、`-`；命令名用 `panel-prompt-add`。命令在 `session.start` 注册。
- **页签**：`TABS` 增加 `other`（短名 `其他`），热键 `5`；页脚 `1–4 页签` 改为 `1–5 页签`；窄屏短名与断点同步到 `docs/UI-SPEC.md` 与测试。
- **剪贴板**：`$.ui.copy({ text, surface: press.surface })`；`isCopied` 为真才计数。终端 OSC 52 可能无法回报真实结果，按引擎返回值记录。
- **布局**：沿用方向 D——入口页是标准列表页（页签 → 规则线 → 行 → 页脚 → 分支轨道）；功能页是安静页（无页签/轨道，右上返回）；行用 `plain` Button，无 emoji。
- 引擎硬约束：见 `docs/SKILL.md`；UI 规范：见 `docs/UI-SPEC.md`。
