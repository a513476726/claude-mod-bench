# bench 面板 UI · 方向 D

面板是终端里的一块固定宽度页面。方向 D 只有一条中心：**状态是第一列，不是整行底色；结构靠整宽规则线与缩进，不靠卡片。**

## 何时用

- 新增/修改任何页签、列表、状态筛选、详情、下钻、diff、文件预览；
- 调整配色、间距、列宽、页签、分支轨道；
- 评审 UI 改动是否合规。

## 设计前置门（强制）

任何 UI 设计、评审或实现前，先调用 `frontend-design:frontend-design` skill，并按「先设计、后编码」的顺序：

1. 读本文与 `docs/UI-SPEC.md`，核对本次涉及的区域；
2. 列出本次区域的规范缺口；
3. 先补齐规范（本文或 `docs/UI-SPEC.md`），再写 UI 代码；
4. 产出设计计划与可验收 checklist。

终端只有一套字体与主题令牌：`frontend-design` 的视觉建议 MUST 落到 `INK` / `Tone` / `STATUS_TAG` / `SP` / `cellsOf`，不得引入 hex、新字体、emoji、背景块或网页式动效。未补齐规范，不得进入 UI 编码。

## 三层，按序读

1. `docs/UI-SPEC.md` —— 完整规范（引擎硬约束 §1 不可协商）。
2. `hooks/ui.tsx` —— 规范的代码化身：令牌 + 纯函数构件。
3. 本文 —— 只讲**怎么用**与**最容易犯的错**。

- 详情 / 下钻 / diff / 文件 / 全文：**没有页签、没有状态轨道、没有分支轨道**；只有页头、规则线、正文、右上角返回。
- 所有页面没有卡片、没有圆角边、没有左右竖线。

## 构件（唯一绘制入口）

| 构件 | 用途 | 规则 |
|---|---|---|
| `SP` | 间距：`inline`（2）/ `group`（2）/ `section`（1） | 只引用，不写字面量 |
| `INK` | 结构灰阶：`frame` / `muted` / `body` / `accent` | 规则线、字段标签、正文 |
| `Tone` | 状态色：`claude` / `warning` / `error` / `success` / `subtle` | 只落在状态标签 |
| `STATUS_TAG` | 状态 → 全称 / 2 字 / 1 字 / 色 | 唯一状态词表，不在页面里另写 |
| `ruleOf(columns)` | 整宽 `─` 规则线 | 输出恒为 `columns` 格 |
| `rowOf(line, columns)` | 平铺行：左 2 格 + 内容 + 右补齐 | 输出恒为 `columns` 格 |
| `lineOf` / `widthsOf` | 列定义渲染 | 只有一个 `Fill` 列，且最后 |
| `footerOf(left, right, columns)` | 页脚两端对齐 | — |
| `pageTitleOf(...)` | 详情标题折行 + 返回预留 | 不截断 |

`panes.tsx` 里的 `ListPage`、`QuietPage`、`StatusRail`、`BranchRail`、`PageHead` 是这层之上的组合，**页面只该用它们**。

## 最容易犯的错

### 1. 状态标签不是行内装饰

- 每行第一列是状态标签：`进行 / 待办 / 异常 / 完成 / 无单`。
- 标签是行内**唯一带色元素**；`done` / `age` / `repo` 一律 muted，`name` 正文色。
- 选中行只加 `▸` + `name` bold；**不改背景、不改标签色**。
- 不再用 `* o ! + .`、`◆`、`↻` 等行首符号。

### 2. 状态轨道必须一行

- `全部 14   进行 3   待办 2   异常 1   完成 7   无单 1`
- 超出宽度从右侧丢状态，**永不换行**；<56 列用紧凑形式。
- 每个状态一行标题 = 直接违反方向 D。

### 3. 没有卡片

- 规则线是唯一的分段结构：页签下、状态轨道下、页脚上。
- 不画 `╭ ╮ ╰ ╯`、不画左右 `│`、不加卡片内边距。
- 分支是页脚轨道，不是卡片；详情没有卡片边。

### 4. 详情是安静页

- 页签、状态轨道、分支轨道在详情页全部消失。
- 标题完整折行；第一行右侧给返回留 10 格；不得 `endClip`。
- 字段标签纯文本、无 emoji；标签列 8 格（<56 列 6 格）；值折行不截断。
- 返回：`← 返回`，`b`，浮在右上角，`top = scroll.offset`；`DetailChrome` 必须是根节点最后一个子元素。

### 5. 页签

- 标签：`OpenSpec` / `对话` / `MCP` / `提示音`；**无 emoji、无 `◉`**。
- 选中：`plain` + accent + bold，无括号、无热键编号。
- 未选中：默认 Button + `hotkey`，`[ 对话 ]` 是引擎唯一的热键渲染。
- 不要给选中页签加 `hotkey`（会画 `1:`）；不要用背景色。

### 6. 列

- 列定义只有一处（`LIST_COLS` / `CONV_COLS` / `MCP_COLS` / `SOUND_COLS`），表头（如有）与数据行同出。
- 所有列左对齐；只有一个 `Fill` 列且最后。
- 窄屏丢列顺序：`repo → age → 次要筛选 → 状态轨道低优先级 → 分支预览按钮`。
- 中文按 `cellsOf` 计宽（2 格），**永远不要用 `padEnd` / `.length` 补列**。

### 7. 分支轨道

- 一仓一行，**绝不横排**；根 `*` accent，子 `|` frame；名称 14 格（<56 列 9 格）。
- 脏工作区 `+N` warning + `预览`；干净工作区无彩色、无按钮。
- 最多 3 行；超出 `… 还有 N 个仓库` + `查看全部`。
- 分支名保留末 7 位：`develop_20_20261012001` 与 `…084` 前 20 位相同，只截尾无法区分。

### 8. 高度预算

```
列表可见行 = bodyRows
           − 页签 1
           − 规则线 1
           − 状态/统计轨道（1 或 2）
           − 次要筛选 1（仅 OpenSpec）
           − 规则线 1
           − 规则线 1（页脚上方）
           − 页脚 1
           − 分支轨道（0 到 4）
```

- 分支轨道行数 = `n === 0 ? 0 : min(n, 3) + (n > 3 ? 1 : 0)`。
- 加任何固定行都要同步减 `room`，否则底部页脚/分支被裁。
- `列表可见行 < 2` 时交给引擎滚动，不手工切片。

### 9. 颜色

- 结构 = 灰阶：规则线 `INK.frame`、次要文字 `INK.muted`、正文默认。
- 状态 = 标签：`claude` 进行 / `warning` 待办 / `error` 异常 / `success` 完成 / `subtle` 无单。
- 上下文读数 `CTX` 也是状态色：<70% 用 `subtle`，≥70% `warning`，≥90% `error`；只出现在会话统计轨道行尾与 AbovePrompt 横条，读数本身不上整行色。
- 一屏允许 5 个状态标签色，但只在同一列；**不允许整行上色、不允许背景块**。
- 干净工作区的分支轨道不应有任何彩色；禁止 hex。

### 10. 字符

- 安全集：`─` `▸` `*` `|` `←` `↑↓` `…` `·`（仅散文分隔）`▶`（仅 `▶ 试听`）。
- **禁用**：emoji、Nerd Font、`◉ ● ○ ★ ⚠ ▼ ■ ◆ ▏`、Box Drawing 圆角/竖线。
- 新增符号前确认 EAW 为 Neutral / Narrow，并同步规范。

## 各页签标签

| 页签 | 标签 |
|---|---|
| OpenSpec | 进行 / 待办 / 异常 / 完成 / 无单 |
| 对话 | 输入 / 提问 / 续轮 / 异常（异常覆盖原类型） |
| MCP | MCP / 本地（结构标签，subtle） |
| 提示音 | 开（success）/ 关（subtle） |

## 窄屏

- 80 / 64：完整列。
- 56：丢 `repo`，保留 age。
- 48：标签可用 2 字；丢 age/repo。
- 40：标签缩 1 字（进/待/异/完/无）；页脚右侧 `1–4`。
- 24：页签短名/点击；状态轨道只留 `全部/进行/异常`；分支隐藏或 1 行摘要；返回 `←返回`。

任何宽度下都不得横向溢出。

## 改完必做

1. 在 `hooks/ui.test.tsx` 断言每一行显示宽度 == `bodyColumns`（含中文标签、24 / 40 / 80 列）。
2. 24 / 40 / 64 / 80 列下：状态轨道不换行、标签不溢出、页脚可见、返回不压标题。
3. 状态筛选：点标签过滤、点 `全部` 清除、计数正确；仓库/时间筛选保留。
4. 详情：标题折行不截断；字段值折行；返回 `b` 可退；滚动提示正确。
5. 分支：无卡片、脏分支 `预览`、干净分支无彩色；`… 还有 N` 正确。
6. `claude plugin test .` 全过；`tsc` 0 错误；`claude plugin validate .` 通过。
7. 同步 `docs/UI-SPEC.md`（§2 骨架 / §3 高度 / §4 构件 / §5 颜色 / §6 字符 / §7 窄屏）。

## 反例

| 写法 | 为什么 |
|---|---|
| 整行取状态色 | 颜色泛滥，扫读先被底色分走；状态应是标签列 |
| 每个状态一行标题 | 5 个标题吃掉 5+ 行；用一行状态轨道 |
| 状态轨道换行 | 高度爆炸；必须一行，从右侧丢 |
| 选中行加背景色 | 方向 D 只允许 `▸` + bold |
| 用 `* o ! + .` 代替标签 | 需要先学符号；方向 D 用文字标签 |
| 卡片/圆角/左右竖线 | 方向 D 没有卡片；规则线才是结构 |
| 页面自绘规则线/列宽 | 宽度与截断逻辑各写一遍，必然错位 |
| 详情页保留页签/状态/分支 | 阅读页需要全部宽度 |
| 详情标题 `endClip` | 详情存在的理由就是看全 |
| 字段标签带 emoji | 宽度失控；方向 D 字段纯文本 |
| 页脚只显示总数 | 用户不知还有多少没看到 |
| 分支横排 | 80 列必然挤成一团 |
| 分支做回卡片 | 方向 D 去掉卡片；分支是页脚轨道 |
| 干净分支上绿色 | 绿色泛滥，「干净」失去意义 |
| 加卡却不改 `room` | 底部页脚/分支被挤出屏幕 |
| 用 `marginTop` 做间距 | Pane 内不生效 |
| 硬编码 hex 颜色 | 不跟随用户主题 |
