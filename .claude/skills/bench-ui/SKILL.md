# bench 面板 UI

面板是终端里的一块固定宽度区域。它的规范只有一条：**每一页都由同一套构件拼成**，没有页面自己决定边框、留白、颜色或列宽。

## 何时用

- 新增/修改任何页签、区域、列表、详情、下钻、diff 视图；
- 调整配色、间距、图标；
- 评审 UI 改动是否合规。

## 三层，按序读

1. `docs/UI-SPEC.md` —— 完整规范（引擎硬约束 §1 不可协商）。
2. `hooks/ui.tsx` —— 规范的代码化身：令牌 + 纯函数构件。
3. 本文 —— 只讲**怎么用**与**最容易犯的错**。

## 构件（唯一绘制入口）

| 构件 | 用途 | 规则 |
|---|---|---|
| `SP` | 间距：`inline`（卡内左右，**2 格**）/ `group`（同行间隔）/ `section`（卡间空行） | 只引用，不写字面量 |
| `INK` | 结构灰阶：`frame` / `muted` / `body` / `accent` | 框线、分隔、表头一律灰阶 |
| `ICON` | 区域图标表（`📋 💬 🔌 🔊 🔀`） | **emoji 只允许出现在页签与卡片标题** |
| `topEdge(title, aside, columns, icon)` | 卡片上边线（引擎 Box 无 `title`，只能自绘） | 输出恒为 `columns` 格 |
| `cardRow(line, columns)` | 卡内一行（左右各留 1 格，无竖线） | 输出恒为 `columns` 格 |
| `bottomEdge(columns)` | 下边线 | 同上 |

| `lineOf(cols, cells, inner)` | 列表行 / 表头共用列定义 | 只有一个 `Fill` 列，且最后 |
| `widthsOf(cols, inner)` | 列宽计算（`Length` + 单 `Fill`） | 窄屏自动收缩，名称列吸收 |
| `headOf(title)` / `ruleOf(inner)` / `footerOf(...)` | 卡内小标题 / 整宽横线 / 底部两端对齐 | — |

`panes.tsx` 里的 `Card`、`CardLine`、`CardRule`、`screen` 是这层之上的组合，**页面只该用它们**。

## 页面骨架

```
页签栏（卡片外，1 行）
空行
╭─ <icon> <区名> ────────── · <右侧摘要> ╮     ← 主卡
  <卡内内容：分区 / 筛选 / 表头 / 行 / 页脚>     ← 无左右竖线
╰────────────────────────────────────────────╯
空行
╭─ 🔀 分支 ───────────────── · <仓库数> ╮      ← 分支卡
  * <仓库>    <分支>
╰────────────────────────────────────────────╯
```

- 所有卡片**同宽**（= `bodyColumns`），卡间恒 1 行空行。
- **只画上下圆角边，不画左右竖线**：竖线要每一行自己补，行里有 `Button` 或多个 `Text` 时列宽不受控，必然错位。
- 详情 / 下钻 / diff：同一张主卡，**层级标题就是卡片标题**；返回按钮浮在右上角。
- 全屏正文（读长文）是**安静页**：无页签、无分支卡，只有卡与返回。

## 高度预算（最容易错的地方）

每张卡多占 **2 行边框**。`drawPane` 里：

```
列表可见行 = bodyRows − 页签 1 − 空行×2 − 分支卡(2 + 仓库行) − 主卡边 2 − 卡内固定行
```

- 加任何卡内固定行（表头、分隔、小标题），都要同步减列表的 `room`，否则底部被裁。
- 仓库行默认 5 行；超出时末行「… 还有 N 个仓库」，右下角「查看全部」按钮（展开后变「收起」，显示全部）。

## 颜色

- **列表行整行取所属分区的 `toneOf` 颜色**，行内符号与分区标题同色——一行一个色，读得出分组。

- **结构 = 灰阶**：框线 `INK.frame`、次要文字 `INK.muted`、正文默认。
- **颜色只标状态**：进行中 `claude`、异常 `error`、待归档 `warning`、完成 `success`。
- 一屏同时出现的彩色语义 ≤ 3 种；干净工作区的分支卡**不应有任何彩色**。
- 禁止 hex 颜色。

## 图标

- 页签、卡片标题：用 `ICON` 表。
- 分区标记 `* o ! + .`、光标 `▸`、返回 `←`、试听 `▶` 一律单宽字符。
- **表头与列表行不得出现 emoji**。
- **详情页是例外**：卡片标题前带区域 emoji，字段标签带图标（`🕒 时间`、`📁 仓库`）。这是用户明确要求的「标题前尽量用 emoji」。
- **表头与数据行必须出自同一张 `LIST_COLS`**，全部**左对齐**——两套列宽必然漂移。
- **详情值必须 `wrap` 换行，不得 `truncate-end`**：长路径、文件名、任务原文正是详情要展示的东西。

## 详情页

- 独立卡片页；标题 `╭─  <emoji> <条目名>`，`╭─` 与 emoji 之间**留 1 格**，和卡内行内缩对齐。
- 字段：标签列 10 格（`emoji + 空格 + 字段名`），**所有字段的值从同一列起**（带不带 emoji 都按 10 格补齐）；值占满剩余宽度。
- **值折行由 `wrapCells(line, room)` 自己做**，不要交给引擎的 `Box flexGrow`：Pane 行宽是本模块排的，引擎判断不同时值会整段消失。
- 值多行时，末行末尾注明「（共 N 行）」；裸文本行续行首列画 `│`。
- **返回按钮挂在卡片上边线那一行**（`Card` 内部），不是包住整张卡的外层 Box——外层高等于正文高，长文件时按钮会滚走。
- **详情 / 下钻 / 文件 / 全屏正文是独立页面**：页签 + 一张卡，**不带分支卡**。分支卡只属于列表页。
- **折行必须先扣行首占位**（内缩 + 标签列 / `│` / `1. ` 序号），否则行比卡片长几格，引擎会二次折断。

## 卡内分区（输入 / 回答 / 任务组）

- 用左缘竖线 `▏`（`inactive`）标出区块边界，**每行都画**，上下界才看得见。
- 标题**一律「emoji + 名称」**（`▏ 🔧 工具`、`▏ 🎫 用量`），**不要用 `── 标题`**——同一页里两种写法不统一。
- 正文在标题基础上再缩 `SECTION_INDENT`（4 格）。
- 正文**按区块内宽折行**（`wrapCells`，宽度扣掉缩进），**绝不 `truncate-end`**。
- 折叠说明与「查看全部」同样贴线、缩到正文列。

## 字符宽度

- 中文按 `cellsOf` 计宽（2 格），**永远不要用 `padEnd`/`.length` 补列**。
- 新增符号前确认 EAW 为 Neutral / Narrow；Box Drawing（`╭ ╮ ╰ ╯ ─`）只用于卡片上下边，卡片不画左右竖线 `│`。
- 引擎 `Box` 的 `children` 类型不接受 fragment（`<>…</>`）——列表子节点用 `Box` 包一层或直接展开。

## 改完必做

1. 在 `hooks/ui.test.tsx` 断言**每一行显示宽度 == 卡片宽度**（含中文标题、窄屏）。
2. `claude plugin test .` 全过；`tsc` 0 错误；`claude plugin validate .` 通过。
3. 同步 `docs/UI-SPEC.md`（§2 间距 / §3 布局 / §4 组件 / §5 颜色 / §6 图标）——规范是契约，改行为必须改它。

## 反例

| 写法 | 为什么 |
|---|---|
| 页面自己 `─` 拼标题 | 宽度/标题互斥逻辑会各写一遍，必然错位 |
| 直接写 `color="success"` 给分支名 | 分支名是结构，不是状态；只有脏工作区才上色 |
| `padCells` 后再空一格补差 | 中英文混排会差 N 格，列错位 |
| 给卡内行补左右竖线 `│` | 行宽不受控，竖线会错位；只靠上下边划区域 |
| 全屏正文里保留页签 | 长文阅读是独立页，旁边不该有出口 |
| 加卡却不改 `room` | 底部页脚/分支卡被挤出屏幕 |
